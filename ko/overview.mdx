### 개요

기업에서 음성 대화형 Agent(Voice & Conversational Agent)를 구축하고 배포할 때는 엔지니어링 작업의 분산, 실행 파라미터 최적화의 어려움, 외부 업무 시스템 연동의 복잡성, 배포 후 품질 모니터링의 어려움과 같은 과제가 흔히 발생합니다. 음성 인터랙션은 실시간성, 안정성, 서비스 경계에 대한 요구 수준이 매우 높습니다. 기존 방식처럼 프롬프트 관리가 분산되고, 통신 경로를 코드에 하드코딩하며, 정량적 검증 수단이 부족한 테스트 절차를 사용하면 응답 지연, 일관성 없는 응대, 업무 연계 단절로 이어질 수 있습니다.

**Daisybell Agent Lab은** 기업용 AgentOS(Agent 운영 체제)의 핵심 플랫폼인 Daisybell Agent Lab은 음성 및 대화형 Agent의 연구·개발부터 프로덕션 운영까지 전 생애주기를 관리하는 문제를 해결합니다. 분산된 설정 관리, 도구 연동, 지식 관리, 프롬프트 엔지니어링을 하나의 프로덕션 환경으로 통합해 기업이 낮은 비용과 높은 신뢰성으로 Agent 업무를 도입하도록 지원합니다.

### 실무 적용의 전체 사이클

음성 Agent를 배포하고 운영하려면 엄격한 엔지니어링 거버넌스와 데이터 검증이 필요합니다. Daisybell Agent Lab은 품질 게이트와 데이터 피드백을 중심으로 전체 생애주기 관리 모델을 제공합니다.

`생성 → 평가 → 배포 → 평가 → 최적화 → 평가 → 배포`

1. **생성(Build):** 지식 자산, 외부 도구, 프롬프트, 실행 파라미터를 통합해 Agent의 초기 구조를 설계하고 업무 로직을 구성합니다.
2. **배포 전 평가(Pre-release Evaluation):** Agent QA로 자동 회귀 테스트와 시뮬레이션 시나리오 검증을 수행합니다. 응대 문구의 정책 준수 여부와 도구 호출 정확도를 검증해 엄격한 배포 승인 기준을 마련합니다.
3. **최초 배포(Initial Deployment):** 테스트를 통과한 버전을 프로덕션 환경에 배포하고 음성 회선 또는 통신 채널에 연결해 실제 업무 트래픽을 처리합니다.
4. **배포 후 평가(In-production Evaluation):** 실제 프로덕션 트래픽을 바탕으로 Evals(평가) 모듈에서 작업 완료율, 상담원 전환율, 업무 전환 지표를 추출합니다. Agent Observer로 대화 이상 원인을 분석해 정성·정량 평가를 완료합니다.
5. **전략 최적화(Optimization):** 평가에서 확인된 지식 공백, 오해가 발생한 지점, 인터랙션 지연 문제를 개선하기 위해 Cerebra 및 Configuration에서 프롬프트를 미세 조정하고 지식을 보완하거나 파라미터를 조정합니다.
6. **회귀 평가(Regression Evaluation):** 최적화한 반복 버전을 QA 테스트 세트에 다시 적용해 비교 검증합니다. 새 전략이 기존 문제를 해결하면서 기존 업무 로직의 회귀 오류를 일으키지 않는지 확인합니다.
7. **재배포(Re-deployment):** 검증을 통과한 새 버전으로 프로덕션 환경의 기존 버전을 중단 없이 교체합니다. 서비스 업그레이드 사이클을 완결하고 업무 변화에 맞춰 Agent 역량을 지속적으로 발전시킵니다.

이 사이클을 통해 Agent 성능 최적화를 경험 중심에서 데이터 중심으로 전환하고, 모든 버전 반복의 추적 가능성과 안정성을 확보합니다.

### Daisybell Agent Lab 기능 아키텍처

Daisybell Agent Lab은 Agent 구축, 연결, 거버넌스, 테스트, 평가, 관측, 사람과 AI의 협업까지 전체 흐름을 아우르는 9개의 핵심 기능 모듈로 구성됩니다.

#### 1. Agent Builder

- Agent의 구체적인 설정과 기능을 생성·편집하고, 운영에 필요한 지식 자산, 스킬 설정, 실행 파라미터를 지속적으로 관리합니다. 변수 정의, 모델 Temperature, 맞장구 전략, 배경음, 끼어들기(Interruption) 전략 등 Agent 실행 파라미터와 고정 문구를 한곳에서 관리합니다.

#### 2. Knowledge

- Agent가 사용할 지식 자산을 통합 관리합니다. 구조화된 지식 베이스의 유지 관리를 지원하고, Kadapter 도구로 외부 비정형 지식을 분해·정제해 구조화된 형태로 입력합니다. 기업 지식을 원본 문서에서 관리 가능한 자산으로 전환해 검색 및 호출 과정의 정확성과 유지 관리성을 확보합니다.

#### 3. Agent QA (품질 게이트 및 자동화 테스트) (알파 버전 운영 중)

- 텍스트와 음성 등 멀티모달 인터랙션을 정성·정량적으로 디버깅하는 도구를 제공하며, 배포 승인 테스트와 자동 회귀 테스트를 지원합니다. Agent 배포를 위한 신뢰할 수 있는 품질 기준을 마련하고, 버전 업데이트 시 정량화된 테스트 결과를 비교해 프로덕션 장애를 줄입니다.

#### 4. Evals (평가 및 지표 관리 센터) (정식 출시 전)

- Agent의 핵심 업무 지표(KPI)와 품질 평가 기준을 통합 정의·설정·추출합니다. 다음 두 단계의 평가 방식을 지원합니다.비정형 대화 음성을 구조화된 업무 KPI 데이터로 전환해 감에 의존한 최적화의 한계를 줄이고, Agent를 지속적으로 개선할 객관적이고 정량적인 근거를 제공합니다.

  - **실시간 지표 추출(Real-time Metrics):** 대화 중 발생한 트리거 이벤트, 함수 호출 상태, 노드 도달률을 실시간으로 포착합니다.
  - **통화 후 AI 추출(Post-call AI Extraction):** 전체 통화 Transcript에서 텍스트와 의도를 자동으로 추출하고, 작업 완료율, 상담원 전환 사유, 규정 준수 위험 지점 등 정량 기준을 정의합니다.

#### 5. Agent Operator (전체 프로세스 관측 및 작업 관리) (베타 버전 운영 중)

- Agent의 업무 성과와 실행 과정을 전반적으로 모니터링하고 진단하며, 다음 네 가지 구성 요소를 제공합니다.

  - **Dashboard (운영 대시보드):** 계층별 시각화 대시보드를 제공합니다.
  
    - *표준 대시보드(Standard Dashboard):* 호출량(Call Volume), 평균 처리 시간(AHT), 도구 사용률, 서비스 품질을 모니터링합니다.
    - *맞춤형 업무 대시보드(Custom Dashboard):* Evals가 추출한 업무 KPI를 차트로 자유롭게 구성해 특정 업무 시나리오의 전환율과 ROI를 추적합니다.
  - **Record Detail (통화 기록):** 통화 내용을 상세히 기록하고, 대화 내용을 한 건씩 확인하거나 통화 오디오를 재생할 수 있습니다. Agent와 최종 사용자의 상호작용을 빠짐없이 기록합니다.
  - **Analysis Trace (최적화 진단 뷰) (알파 내부 테스트 중, 미공개):** 단일 인터랙션의 턴별 텍스트, 음성 녹음 파형, ASR 수정 비교, 모델 첫 토큰 지연 시간(TTFT), 도구 호출 Request/Response 페이로드, 지식 참조 경로를 확인할 수 있습니다.
  - **Task Manager:** 아웃바운드 Agent의 작업 배치 설정, 동시 실행 상한, 실패 시 재발신 전략, 번호 대역별 규정 준수 라우팅을 제공합니다.

블랙박스 운영 위험을 해소하고, 상위 수준의 업무 KPI부터 중간 수준의 보안·규정 준수, 개별 통화 로그까지 전체 경로를 투명하게 관리합니다.

#### 7. Human Agent Console (사람-AI 협업 상담원 워크스테이션) (정식 출시 전)

- 사람과 AI의 긴밀한 협업을 위해 상담원과 관리자가 함께 사용하는 통합 업무 플랫폼입니다. 기존 콜센터에서 사람이 개입하는 지점을 재설계해 실시간 모니터링, 즉각적인 개입, 성과 평가, 상담 기록의 원활한 인계까지 완결된 협업 흐름을 제공합니다.

  - **실시간 다중 세션 모니터링(Real-time Multi-session Monitoring):** 상담원이나 관리자는 콘솔에서 여러 AI Agent가 동시에 처리하는 통화를 모니터링할 수 있습니다. 턴별 텍스트 변환, 감정 변화 표시, 슬롯 수집 진행 상황, 잠재 위험 알림을 실시간으로 확인합니다.
  - **원활한 개입 및 즉시 인계(Intervention & Human Takeover):** AI가 전환을 요청할 때까지 기다리는 기존 방식에서 벗어나, 상담원은 실시간 통화 상황과 고객 감정에 따라 언제든지 클릭 한 번으로 개입하거나 통화를 완전히 인계받을 수 있습니다(Takeover). AI 모드에서 상담원 모드로 원활하게 전환해 AI가 예외 상황을 이해하지 못해 고객 불만으로 이어지는 일을 방지합니다.
  - **AI 응대 평가 및 교정(AI Performance Evaluation & Feedback):** 상담원은 모니터링하거나 통화를 인계받는 동안 AI의 현재 턴에 대한 답변 정확도, 응대 표현의 적절성, 도구 호출 결과를 실시간으로 표시하고 평가할 수 있습니다(Feedback). 평가와 주석 데이터는 QA 및 Evals 모듈로 실시간 전달되어 상담원의 교정이 AI 개선으로 이어지는 선순환을 만듭니다.
  - **ACW 정보의 원활한 인계(Seamless ACW Streaming):** 통화를 전환하거나 인계할 때 AI가 자동 생성한 대화 요약(Summary), 수집된 변수와 엔터티, 후처리(ACW) 작업 초안이 상담원 화면으로 자연스럽게 전달됩니다. 상담원은 고객 배경을 다시 묻지 않고 주요 사항만 확인하거나 보완해 빠르게 기록을 완료할 수 있어 평균 처리 시간(AHT)을 크게 줄입니다.

기존 콜센터의 디지털·AI 전환 요구에 적합합니다. AI가 빈도가 높은 일반 문의를 처리하고 상담원이 실시간 모니터링, 개입, 품질 교정을 담당하는 하이브리드 서비스 모델은 팀의 동시 처리 역량을 크게 높이는 동시에 고위험·복잡한 시나리오의 서비스 품질을 보장해, 원활하고 위험이 낮은 아키텍처 전환을 지원합니다.



### 요약

Daisybell Agent Lab은 표준화된 모듈 구성과 생성 → 평가 → 배포 → 평가 → 최적화 → 평가 → 배포의 전 생애주기 관리 사이클을 통해 복잡한 음성 및 대화형 Agent 개발을 관리·관측·정량화할 수 있는 엔지니어링 전달 프로세스로 전환합니다. 설정 분산, 테스트·평가 부족, 시스템 연동 비용 문제를 해결해 기업이 안정적인 Agent 운영 체계를 구축하고 다양한 업무 시나리오에 효율적으로 도입해 지속적으로 발전시키도록 지원합니다.
