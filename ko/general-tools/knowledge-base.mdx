title: "지식 베이스(Knowledge Base)"
---

Knowledge Base(지식 베이스)는 Agent Lab의 지식 입력 및 관리 기능입니다. 프로젝트별로 로컬 문서를 구성하고 파일을 업로드하면 시스템이 비동기적으로 문서를 분석해 지식을 추출합니다. 추출 결과를 확인·검수·편집하거나 지식 항목을 직접 추가할 수 있습니다.



추출 결과는**Q&A(질문과 답변 쌍)**형식입니다.

### 지식 베이스 페이지 이해하기
**Knowledge Base** 에 들어가면 페이지 왼쪽에는 프로젝트 목록이 표시되고, 오른쪽에는 현재 선택한 프로젝트의 파일 목록이 표시됩니다.
- **프로젝트 목록**: 프로젝트 이름과 프로젝트에 포함된 파일 수를 표시하며, 생성일이 최신인 순서로 정렬됩니다.
- **파일 목록**: 프로젝트 이름, 상태, 업로드 날짜, 지식 파일에 포함된 지식 항목 수, 작업 메뉴를 표시합니다.

### 프로젝트 생성 및 관리

프로젝트는 파일을 분류하는 단위입니다. 파일을 업로드하기 전에 프로젝트를 만들거나 기존 프로젝트를 선택하세요.

#### 프로젝트 생성

1. **New Project(새 프로젝트)**를 클릭하면 생성 팝업이 열립니다. 프로젝트를 하나도 만들지 않은 상태에서 지식 베이스 페이지에 들어가면 이 팝업이 자동으로 열립니다.
2. **Project Name(프로젝트 이름)** 에 이름을 입력합니다. 이름은 최대 50자이며 기존 프로젝트와 중복될 수 없습니다. 시스템은 이름 앞뒤의 공백을 제거합니다.
3. **Language**에서 지식 추출 결과의 언어를 선택합니다.
4. **Match Strategy(일치 전략)**을 선택합니다. 기본값은 **Prioritized Match(우선 일치)**입니다.
5. **Create Project**를 클릭해 프로젝트를 생성합니다.

![](/images/ko/general-tools/knowledge-base/img-2.png)

#### 일치 전략 선택

일치 전략은 검색 시 프로젝트에서 ‘필수 일치 지식’으로 표시된 항목을 어떻게 처리할지 결정합니다.

| 전략 | 필수 일치 지식 처리 방식 | 일반 지식 처리 방식 |
|-|-|-|
| **Prioritized Match(우선 일치)**(기본 전략) | 필수 일치 지식이 하나면 해당 항목을 바로 반환합니다. 여러 개면 BM25 알고리즘과 벡터 유사도를 사용해 가장 관련성이 높은 항목 하나를 반환합니다. | 일반 검색 절차에 따라 처리합니다. |
| **Match All(모두 일치)** | 프로젝트의 모든 필수 일치 지식을 바로 반환하며, BM25 알고리즘, 벡터 검색 또는 대규모 언어 모델을 통한 추가 선별은 수행하지 않습니다. | 일반 검색 절차에 따라 처리합니다. |

#### 프로젝트 삭제

1. 프로젝트 이름 위에 마우스를 올리면 삭제 아이콘이 표시됩니다.
2. 삭제 아이콘을 클릭합니다.
3. 확인 팝업에서 삭제를 확정합니다.



### 지식 파일 상태 확인

프로젝트를 선택하면 파일 목록이 업로드 시간의 최신순으로 정렬됩니다. 기본적으로 페이지당 파일 20개가 표시됩니다. 베타 버전에서는 파일 목록 검색을 지원하지 않습니다.

파일 상태에 따라 수행할 수 있는 작업이 달라집니다.

![](/images/ko/general-tools/knowledge-base/img-3.png)

| 상태 | 설명 | 수행 가능한 작업 |
|-|-|-|
| **Processing(처리 중)** | 파일 업로드가 완료되어 분석 중입니다. | 사용할 수 있는 작업이 없습니다. ‘…’ 버튼을 클릭할 수 없으며 상세 페이지에도 들어갈 수 없습니다. |
| **Extract Failed(추출 실패)** | 분석 중 예외나 오류가 발생해 지식 추출이 중단되었습니다. | 다시 처리, 삭제 |
| **Extracted(추출 완료)** | 파일 분석이 완료되었습니다. | 상세 보기, 삭제 |

**Extract Failed** 상태의 파일에서 ‘다시 처리’를 클릭하면 비동기 분석이 다시 시작되고 파일 상태가 **Processing** 으로 바뀝니다.

**Extracted** 상태인 파일은 파일 행 또는 **View Details(상세 보기)**를 클릭해 지식 분석 상세 페이지로 이동할 수 있습니다.

### 파일 업로드 및 지식 추출

![](/images/ko/general-tools/knowledge-base/img-4.png)

#### 파일 요구 사항

| 항목 | 요구 사항 |
|-|-|
| 지원 형식 | .pdf, .docx, .txt, .xlsx, .md |
| 파일당 최대 크기 | 10.00 MB |
| File Description(프롬프트) | 최대 400자, 기본값은 빈칸입니다. |

파일 설명(File Description)은 모델이 지식을 추출할 방향을 안내합니다. 파일 주제, 내용 요약 또는 구체적인 추출 요구 사항을 입력할 수 있습니다.

#### 업로드 단계

1. 파일을 넣을 프로젝트를 선택합니다.
2. **Add Knowledge**를 클릭해 **Add Knowledge file** 팝업을 엽니다.
3. 필요에 따라 **File Description(파일 설명)**을 입력합니다.
4. **Upload file(파일 업로드)** 영역에서 로컬 파일을 선택하거나 파일을 업로드 영역으로 끌어 놓습니다.
5. 표시된 파일 이름과 크기를 확인합니다.
6. **Upload & Process**를 클릭해 파일을 업로드하고 분석을 시작합니다.



업로드가 완료되면 파일 상태가 **Processing** 으로 표시됩니다. 상태가 **Extracted**로 바뀌면 추출 결과를 확인하고 검수할 수 있습니다. 업로드에 실패하면 페이지에 오류 메시지가 표시됩니다.

선택한 파일을 바꾸려면 파일 옆의 삭제 아이콘을 클릭하고, 확인 팝업에서 삭제를 확정한 후 새 파일을 업로드합니다.

### 지식 항목 확인 및 관리

파일 처리가 완료되면 **View Details(상세 보기)**를 열어 추출된 구조화 지식을 확인합니다. 지식 항목은 카드 형태로 표시되며 페이지 이동을 지원합니다.

![](/images/ko/general-tools/knowledge-base/img-5.png)



<grid>
<column width-ratio="0.500000">
#### 항목 추가
1. ‘항목 추가’를 클릭합니다. 목록 맨 위에 편집할 수 있는 빈 카드가 표시됩니다.
2. 내용을 입력하고 저장합니다.
</column>
<column width-ratio="0.500000">
![](/images/ko/general-tools/knowledge-base/img-6.png)
</column>
</grid>

#### 항목 편집

1. 카드에서 ‘편집’을 클릭합니다.
2. 해당 텍스트를 수정합니다.
3. 현재 카드에서 변경 내용을 저장합니다.

#### 항목 삭제

1. 카드에서 ‘삭제’를 클릭합니다.
2. 확인 팝업에서 삭제를 확정합니다.
