---
title: "메시지 푸시(Message Push)"
---

메시지 푸시는 통화 태그를 기반으로 알림을 자동 발송하는 플랫폼입니다. 유연한 모니터링 규칙을 설정하면 대량의 통화에서 결제 문제 급증, 불만 증가, 주요 위험 이벤트 발생과 같은 이상 추세를 빠르게 발견하고 여러 채널로 알림을 자동 발송할 수 있습니다.

---

### 1단계: 알림 채널 설정(Notification Channels)

모니터링 규칙을 만들기 전에 알림을 받을 **알림 채널**을 설정해야 합니다. 이메일, Microsoft Teams, 일반 Webhook 등 다양한 연동 방식을 지원합니다.

왼쪽 기본 탐색 메뉴에서 **메시지 푸시(Message Push)클릭합니다.**

![](/images/ko/general-tools/message-push/img-JXvObnA3EoPbNHxLm9Fj3c97p9g.png)



- **1. 채널 목록 및 빈 상태**목록 관리: 채널을 추가하면 목록에서 채널 이름, 유형, 대상 주소, 최근 테스트 발송 상태를 확인할 수 있습니다. 기존 채널을 **편집**, **삭제**하거나 **테스트 발송**할 수 있습니다.

#### 2. 푸시 주소 추가

**‘Push Address’ 탭** 또는 **‘편집’**에서 주소를 추가하거나 편집합니다.



1. **주소 이름**: 알아보기 쉬운 이름을 지정합니다(예: `결제 알림 이메일`).
2. **채널 유형**: 드롭다운 메뉴에서 선택합니다. 현재는 다음 유형을 지원합니다.`이메일(email)`
3. **대상(Target)**: 수신 이메일 주소를 입력합니다.
4. **테스트 발송**: 저장하기 전에 **‘테스트 발송’** 버튼을 클릭해 테스트 이메일을 대상 주소로 보내는 것이 좋습니다.

---



### 2단계: 모니터링 규칙 설정(Rules)



사용할 알림 푸시 주소를 설정한 뒤 통화 태그 기반의 자동 모니터링 규칙을 만들 수 있습니다.

**‘Rules’ 탭** 의 오른쪽 위에서 **‘규칙 추가’**를 클릭합니다. 시스템이 네 가지 주요 설정 영역에서 규칙을 만들도록 안내합니다.

![](/images/ko/general-tools/message-push/img-RXj0bmZbUovFIVxhRmXjrcyLpJf.png)



---

#### 1. 기본 정보 설정

규칙과 트리거 소스를 정의합니다.

- **규칙 유형(Rule Type)**: 드롭다운에서 분류를 선택합니다(예: `정보 푸시`, `알림 푸시`). 메시지 푸시는 ‘알림 푸시’ 유형의 내용에 통화 상세 정보를 추가합니다.
- **규칙 이름(Rule Name)**: 규칙의 업무 목적을 식별하는 필수 항목입니다(예: `결제 실패 급증`).
- **트리거 Agent(Agent)**: 드롭다운에서 데이터 소스 Agent를 선택합니다.
- **트리거 키(Trigger Key)**: 모니터링할 시스템 통화 태그 또는 동적 필드를 드롭다운에서 선택합니다(예: `결제 결과`).
- **태그 유형(Tag Type)**: 선택한 ‘트리거 키’에 따라 시스템이 해당 데이터 유형을 자동으로 식별해 표시합니다.

  - `text` (텍스트)
  - `time` (시간)
  - `number` (숫자)
  - `enum` (열거형)
  - `boolean` (불리언)

---

#### 2. 조건 정의(Conditions)

트리거 필드의 ‘데이터 유형’에 따라 사용할 수 있는 **연산자**와 **일치 값** 입력 컨트롤이 동적으로 바뀝니다.

![](/images/ko/general-tools/message-push/img-QqHHbgdLaoE5r0xKyP6jLHUqpke.png)

![](/images/ko/general-tools/message-push/img-M0WjbCU26oEBhHxJN98jfLeUpqc.png)

조건을 설정할 때 다음 표를 참고하세요.

| 트리거 필드 유형(Tag Type) | 지원 연산자(Operator) | 일치 값 입력 컨트롤 및 상호작용 규칙 |
|-|-|-|
| **텍스트(Text)** | `포함(CONTAINS)` `포함하지 않음(NOT_CONTAINS)` | 표준 텍스트 입력란입니다. 일치 키워드 하나 또는 정규식을 입력할 수 있습니다. |
| **숫자(Number)** | `>` (초과)  `>=` (이상)  `<` (미만)  `<=` (이하)  `=` (같음)  `범위(BETWEEN)` | 숫자 입력란입니다. 특히 `범위(BETWEEN)` 를 선택하면 숫자 입력란 두 개(Min 및 Max)가 표시되며 가운데 `~` 로 두 값을 구분합니다. |
| **열거형(Enum)** | `포함(IN)`   `포함하지 않음(NOT_IN)` | 시스템에서 미리 설정한 열거 값 목록에서 여러 항목을 선택할 수 있는 드롭다운입니다. |
| **불리언(Boolean)** | `예`   `아니요` | 라디오 버튼 그룹입니다. 복잡한 같음 연산자를 설정할 필요 없이 해당 상태를 바로 선택하면 됩니다. |
| **시간(Time)** | `시간 범위(BETWEEN)`   `이후(>)`   `이전(<)` | 24시간제 시간 선택기입니다(형식: `HH:mm`)일 때 `시간 범위(BETWEEN)` 를 선택하면 시간 범위(시작 시간\~종료 시간)를 선택하는 컨트롤이 표시됩니다. 23:00\~다음 날 02:00과 같이 자정을 넘는 범위도 지원합니다. |

---

#### 3. 트리거 규칙 및 빈도 설정(Trigger Strategy)

일회성 이벤트로 인해 알림이 지나치게 자주 발송되는 것을 막기 위해 시간 범위를 기준으로 발송 빈도를 제어합니다.

![](/images/ko/general-tools/message-push/img-GVSlbWRk9oHJoAxJcYKjUdOEp0K.png)



- **시간 범위(Window Minutes)**: 집계할 데이터의 시간 범위를 분 단위로 설정합니다. 예를 들어 `30` 분으로 설정하면 시스템이 직전 30분 동안의 이동 데이터를 계속 분석합니다.
- **트리거 임계값(Threshold)**: 설정한 ‘시간 범위’ 내에서 ‘조건’을 충족한 이벤트의 누적 횟수입니다. 이 값에 도달해야 알림이 발송됩니다.

---

#### 4. 알림 주소 연결 및 미리 보기(Binding & Preview)

규칙이 트리거되면 알림을 보낼 설정된 채널을 지정할 수 있습니다.

- **주소 추가/제거**: **‘+ 주소 추가’** 를 클릭해 규칙에 여러 수신 주소를 연결할 수 있습니다.
- **결과 미리 보기**: 각 주소 옆의 **‘미리 보기’** 버튼을 클릭하면 수신되는 알림 형식을 확인할 수 있습니다.



![](/images/ko/general-tools/message-push/img-SUCgbpdwAooORhx7f3pjWfTIpmg.png)



---

#### 5. 규칙 편집

생성 및 편집 양식 하단에 전체 작업 표시줄이 있습니다.

- **초기화/취소**:

  - *생성 상태*에서는 ‘초기화’가 표시됩니다. 클릭하면 현재 양식에 입력한 내용이 모두 지워지고 기본 상태로 돌아갑니다.
  - *편집 상태*에서는 ‘취소’가 표시됩니다. 클릭하면 현재 변경 사항을 취소하고 목록으로 돌아갑니다.
- **규칙 생성/변경 사항 저장**:

  - 시스템이 이름, 트리거 필드, 조건 등 필수 항목을 모두 확인합니다.
  - 확인이 완료되면 클릭하여 설정을 저장합니다. 규칙을 성공적으로 생성하면 토스트 알림 `‘규칙이 생성되었습니다’`가 표시되고 새 규칙이 목록에 추가됩니다.
- **원클릭 활성화/비활성화**: 카드 오른쪽의 **Switch**를 사용해 규칙을 즉시 활성화하거나 비활성화할 수 있습니다.
- 카드 오른쪽의 **쓰레기통** 아이콘을 클릭하면 규칙을 삭제할 수 있습니다.
