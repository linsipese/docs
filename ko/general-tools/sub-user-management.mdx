### 왼쪽 메뉴에서 “User Management”를 클릭하면 서브 계정 생성 및 관리 페이지로 이동합니다.

![](/images/ko/general-tools/sub-user-management/img-NbOmbc1fooetJ6x8K7KjtfhDpJo.png)

#### 서브 계정 생성

- “Create New User”를 클릭합니다.

![](/images/ko/general-tools/sub-user-management/img-Lm2ubG79Do1a4exGqiXjRdy5pZe.png)

- 생성할 서브 계정 정보를 입력합니다.

  - 사용자 이름: Agent Lab에 표시되는 이름
  - 계정: Admin 계정과 동일한 이메일 도메인 접미사를 사용해야 합니다.
  - 보안 이메일: 생성 중인 계정의 초기 비밀번호가 보안 이메일로 전송됩니다.

![](/images/ko/general-tools/sub-user-management/img-SNJjb6M71oGHNrx6dqljv8JkpKb.png)

#### 서브 계정 로그인

- Admin 사용자가 계정을 생성할 때 입력한 계정(이메일 주소)
- 보안 이메일로 받은 초기 비밀번호
- 서브 계정은 Agent Lab에 처음 로그인할 때 비밀번호를 한 번 재설정해야 하며, 이후 정상적으로 사용할 수 있습니다.

#### 서브 계정 관리

##### 서브 계정 비밀번호 재설정

- 해당 사용자의 현재 비밀번호는 더 이상 유효하지 않습니다.
- 시스템에서 새 임시 비밀번호를 생성해 서브 계정의 보안 이메일로 전송합니다.
- 재설정 후 해당 사용자는 강제로 로그아웃되며 저장하지 않은 작업은 모두 사라집니다.

##### 서브 계정 권한 설정

- 업무에 따라 해당 서브 계정에 필요한 Agent 상세 페이지의 접근 권한을 부여합니다.

##### 서브 계정 비활성화 및 삭제 (Admin 권한)

- 비활성화

  - 해당 사용자는 즉시 시스템 접근 권한을 잃고 더 이상 로그인할 수 없습니다.
  - 계정이 강제로 로그아웃되며 저장하지 않은 작업은 모두 사라집니다.
  - 비활성화 후에도 계정 데이터는 보존됩니다.
- 삭제

  - 해당 사용자는 즉시 시스템 접근 권한을 잃고 더 이상 로그인할 수 없습니다.
  - 계정이 강제로 로그아웃되며 저장하지 않은 작업은 모두 사라집니다.
  - 삭제한 계정 데이터는 복구할 수 없습니다.
