---
title: "플랫폼 도구"
---

플랫폼 도구 (General Tools)는 현재 플랫폼에서 제공하는 여러 관리 및 운영 메뉴를 모아 둔 영역입니다. 화면 메뉴 기준으로 전화번호, 지식 베이스, 내보내기, 메시지 푸시, 사용자 관리 메뉴가 있습니다.

### 도구 메뉴

| 메뉴 항목 | 기능 범주 | 문서 링크 |
|-|-|-|
| 전화번호 관리 (Phone Numbers) | 전화번호 관리 |  |
| 지식 베이스 Beta (Knowledge base) | 지식 베이스 관련 기능 |  |
| 내보내기 센터 (Export Center) | 통화 기록 내보내기 메뉴 |  |
| 메시지 푸시 (Message Push) | 자동 알림 푸시 플랫폼 |  |
| 사용자 관리 (Sub-user Management) | 하위 계정 관리 화면 |  |
