## **Agent 생성 및 구성**

Agent Builder는 Agent를 생성하고 언어, 음성, 대화 전략, 전화 회선 및 Agent 필드를 구성할 수 있습니다.



### **Agent 생성**

1. `Agent 생성` 를 선택합니다.
2. Agent 이름을 입력하고 유형을 선택합니다. 이름은 필수이며 최대 30자까지 입력할 수 있습니다. 선택 가능한 유형은 `Inbound`, `Outbound`, `Chatbot`, `Webvoice`입니다.
3. `기본 설정`으로 이동합니다.

### 기본 설정

#### 기본 생성 및 설정

| **설정** | **설명** |
|-|-|
| `Agent명` | 필수 입력 항목,  최대 30자까지 입력 가능 |
| `Agent 제목` | 선택 항목,  최대 30자까지 입력 가능 |
| `Agent 설명` | 선택 항목,  최대 200자까지 입력 가능 |
| `Agent Avatar` | 선택 항목. 이미지를 업로드하거나 시스템 아바타를 선택할 수 있습니다. 업로드 이미지는 180 × 180픽셀이며 JPG, PNG 등을 지원하고 파일 크기는 2MB 미만이어야 합니다. |



![](/images/ko/agent-builder/agent-create-config/img-IXT0b9SWboc13sxqeuajpcmVpsg.png)

#### 언어 설정

`기본 언어` 는 단일 선택 항목입니다. Agent를 생성하고 저장한 후에는 기본 언어를 변경할 수 없습니다.

`기타 언어` 에는 여러 언어를 추가할 수 있습니다. 저장한 언어는 삭제할 수 없으며 계속 추가만 할 수 있습니다.

선택한 언어마다 ASR 및 TTS 구성 카드가 제공됩니다. 기본 언어 카드에는 `기본 언어` 라벨이 표시됩니다.

#### **액세스 정보 및 키（Webvoice/Chatbot）**

`Webvoice` 유형의 Agent에서는 `접근 정보`에 시스템이 생성한 액세스 URL이 표시됩니다.

![](/images/ko/agent-builder/agent-create-config/img-NvaebXsW0oDWLnxiLu4j4eHhpLb.png)



`Chatbot` 유형의 Agent에서는 접근 정보에 `EID`와 시스템이 생성한 액세스 URL이 포함됩니다.

![](/images/ko/agent-builder/agent-create-config/img-O5qib9edaovsj6xBv4hjJ84Kpgh.png)

### 언어 설정

#### ASR 설정

ASR 구성은 `Inbound`, `Outbound` 및 `Webvoice`에 적용됩니다. 언어별로 ASR 서비스, `VAD Delay (ms)`, `ASR Hotwords`를 설정합니다. VAD 지연의 기본값은 `500`이며 양의 정수로 입력합니다.



핫워드는 하나씩 입력하거나 일괄 가져올 수 있습니다. 기존 목록에 추가하거나 대체할 수 있으며, 중복 핫워드는 자동으로 제거됩니다.

![](/images/ko/agent-builder/agent-create-config/img-AsU6bX7dgoiX7ax3tPKjuV69pyg.png)

#### TTS설정



TTS 구성은 `Inbound`, `Outbound` 및 `Webvoice`에 적용됩니다. 언어별로 음성을 선택하고 표준 녹음을 미리 들을 수 있습니다. 음성에는 `남성` 또는 `여성` 라벨이 표시됩니다.

| 设置 | 说明 |
|-|-|
| `속도(배속)` | 범위는 `0.5x-2x`이며 단계는 `0.1`, 기본값은 `1.0`입니다. |
| `볼륨` | 범위는 `1-100`이며 기본값은 `50`입니다 |
| `발음 사전` | 발음 사전 선택합니다. 기본값은 `Default`입니다. |

![](/images/ko/agent-builder/agent-create-config/img-AMJmbjwiKo6qbcxCLGbjt3wypOd.png)

### 대화 전략 설정

`Inbound`, `Outbound` 및 `Webvoice` Agent는 배경음, 최대 통화 시간 및 `발화 완료 판단`을 설정할 수 있습니다.

배경음은 미리 들을 수 있습니다.



`최대 통화 시간(분)`: 대화를 유지할 수 있는 최대 시간입니다. 기본값은 30분이며, 제한 시간에 도달하면 통화가 강제 종료됩니다.



`발화 완료 판단`: 각 대화 Turn의 완료 여부를 판단합니다. 기본값은 꺼짐입니다.

![](/images/ko/agent-builder/agent-create-config/img-MZI9bGjdCoyqSdxiw8bjBmNYp0f.png)

Chatbot은 `최대 대화 시간`을 설정할 수 있습니다. 범위는 1초부터 24시간까지이며 기본값은 5분입니다. 설정된 시간 내에 사용자가 응답하지 않으면 대화가 종료됩니다.

![](/images/ko/agent-builder/agent-create-config/img-KwcTb9RwIoqOq6x0lQGjVM93p5g.png)

### 전화 회선 설정

전화 회선 설정은 `Inbound`와 `Outbound`에 적용됩니다. `Webvoice`에는 `대표 발신 번호`가 표시되지 않으며, `Chatbot`에는 전화 회선 설정이 제공되지 않습니다.

#### 발신 번호

여러 발신 번호를 추가할 수 있습니다.



`Outbound` Agent는 발신 번호별 전환 동시성을 설정할 수 있습니다. 해당 번호는 발신과 `Transfer Call Tool` 전환에 사용할 수 있으며, 두 용도는 전체 동시성을 공유합니다.

#### 통화 전환 **전용 번호**

사용하지 않는 `Outbound` 회선을 전용 전환 번호로 설정할 수 있습니다. 전용 번호는 전환에만 사용되며, 동시성은 발신 번호의 전환 동시성과 별도로 관리됩니다. 번호를 삭제하면 해당 회선을 다시 선택할 수 없습니다.

![](/images/ko/agent-builder/agent-create-config/img-RT1MbHFcToe45WxL4Q1jHf82pld.png)

### Agent 필드

`Agent 필드`는 시스템 필드와 사용자 정의 필드로 구성됩니다. 시스템 필드는 Agent 유형에 따라 표시되며 워크벤치에서는 편집할 수 없습니다.



#### 사용자 정의 필드

`extra_field`를 생성할 때 필드 이름, 키 이름, 유형 및 기본값을 설정할 수 있습니다. 생성 후 필드 이름은 편집할 수 있지만 키 이름과 필드 유형은 변경할 수 없습니다. 키 이름에는 영문자와 밑줄을 사용할 수 있으며, 필드 유형은 숫자, 배열, 열거형, 부울, 텍스트, 시간으로 구성됩니다.



| 选项 | 说明 |
|-|-|
| `태스크 생성으로 가져오기` | `Outbound`에서만 사용하며 기본적으로 꺼져 있습니다. 켜면 아웃바운드 작업을 통해 해당 필드를 업로드할 수 있습니다. |
| `수동 편집 가능 여부` | 기본적으로 꺼져 있습니다. 켜면 `Agent 상세 - 통화 기록 리스트`에서 필드 값을 직접 편집할 수 있습니다.\| |
| `정렬 가능` | 기본적으로 꺼져 있습니다. 켜면 `Agent 상세 - 통화 기록 리스트`에서 해당 필드를 기준으로 정렬할 수 있습니다. |



시스템 필드 `통화 시작 시간`은 기본적으로 정렬할 수 있으며 이 설정은 변경할 수 없습니다.



![](/images/ko/agent-builder/agent-create-config/img-UvsAbwdmXozYQyxXruUjZ2mUprf.png)

### **Agent 기본 설정 적용 방식（중요）**



현재 Agent 기본 설정과 Agent 스크립트 버전은 서로 독립적으로 편집됩니다. 따라서 Agent 기본 설정을 수정하고 저장해도 기존 Script 버전에는 적용되지 않습니다. 이후 저장하는 스크립트 버전부터 최신 기본 설정 파라미터가 적용됩니다.



따라서 Agent의 기본 설정을 조정하고 저장한 후에는 **스크립트 편집에서 최신 스크립트 버전을 하나 저장해야 합니다（스크립트 버전의 내용은 변경하지 않아도 됩니다）**. 이렇게 저장한 최신 스크립트 버전에는 최신 기본 설정 파라미터가 적용됩니다. 이 버전을 게시하거나 공해해야 하는 경우에는 Test 센터의 버전 목록에서 작업할 수 있습니다.
