title: "Agent 도구 호출"

Tools 모듈은 Agent가 호출할 도구를 관리합니다. 여러 유형의 도구(Functions)를 추가하고 트리거 조건, 고정 응답, 유형별 필드를 설정할 수 있습니다.

### 도구 목록

도구는 한 줄에 하나씩 카드로 표시됩니다. 각 카드에는 다음 항목이 포함됩니다.

- **제목**: 도구 유형 레이블과 `tool_name`이 표시됩니다.
- **설정**: 도구 유형에 따라 해당 필드가 표시됩니다.
- **작업**: 편집 및 삭제를 지원합니다.
- **활성화 상태**: Function을 비활성화할 수 있습니다.

기존 Function을 편집할 때는 Type을 다시 선택할 수 없습니다. 새 도구를 추가하려면 **Add Tool**을 클릭하고 도구 유형을 선택합니다. 그러면 Function이 Tool List에 카드로 추가됩니다.



###  메인 프롬프트에서 도구 참조하기

 메인 프롬프트 편집 영역에서 **Tools**을 클릭하거나 `@` 를 입력해 도구 목록을 엽니다. 도구를 선택하면 편집기에 강조된 도구 태그가 표시됩니다.

<callout emoji="💡">
참고: 추가한 도구는 메인 프롬프트에서 참조하지 않아도 정상적으로 실행될 수 있습니다.  메인 프롬프트에서 참조하면 도구 호출 조건과 범위를 더 구체적으로 안내할 수 있습니다.
</callout>

### Function 유형

#### 전화 전환 (Call Transfer)

Call Transfer는 통화 전환을 구성하는 Function입니다. 다음 필드를 설정할 수 있습니다.

| **필드** | **설명** |
|-|-|
| Function Name | Function 이름 |
| Function Trigger description | Function이 실행될 조건을 설명합니다. |
| Transfer to | 현재 전환 대상은 다음과 같습니다.  <br/>1. 전화번호로 전환  <br/>2. Daisybell 상담원에게 전환 (내부 테스트 기능) |
| Transfer Phone Number | 전환 대상 전화번호입니다. Assigned Human Agent를 선택하면 이 필드는 표시되지 않습니다. |
| Phone Number | 전환 발신에 사용할 전화번호입니다. Assigned Human Agent를 선택하면 이 필드는 사용되지 않습니다. |
| Assigned Human Agent | 지정된 상담원을 선택합니다. |
| Max Answer Wait Time | 최대 응답 대기 시간을 설정합니다. 이 시간을 초과하면 전환을 중단합니다. |
| Recipient Email | 원본 통화 전체 기록을 받을 이메일 주소입니다. 여러 개를 설정할 수 있습니다. |
| Transfer Handling Mode | 전환 처리 모드를 선택합니다.  <br/>1. 전환 통화를 녹음하고, 전환된 전화가 끊기면 통화를 종료합니다.  <br/>2. 전환 통화를 녹음하지 않고, 전환된 전화가 끊기면 통화를 종료합니다. |
| Transfer Success Fixed Reply | 전환 성공 시 사용할 고정 응답을 설정합니다. 여러 언어를 지원합니다. |
| Transfer Failed / No Answer Fixed Reply | 전환 실패 또는 부재중일 때 사용할 고정 응답을 설정합니다. 여러 언어를 지원합니다. |

#### 지식 검색 (RAG query)

 RAG query는 지식 베이스를 검색하는 Function을 구성합니다. 다음 항목을 설정해야 합니다.

- **Function 명**
- **Function 트리거 설명**: Function이 실행될 조건을 Prompt로 설명합니다.
- **지식 베이스 폴더**: 기존 지식 베이스 프로젝트 폴더를 선택합니다.
- **Function 실행 시 고정 응답**: 여러 언어를 지원합니다.

![](/images/ko/agent-builder/tools/img-Ohk2b4XSgoWUyvxg40jjaUJsped.png)



#### 언어 전환 (Language switch)

Language switch는 대화 중 Agent가 사용하는 언어를 전환하는 Function입니다. 두 개 이상의 언어를 설정한 경우에만 사용할 수 있으며, 언어가 하나뿐이면 비활성화됩니다.

다음 항목을 설정해야 합니다.

- **Function 명**
- **Function 설명**: Function이 실행될 조건을 Prompt로 설명합니다.
- **언어 B로 전환할 때 사용할 고정 응답**: 언어 B로 작성합니다.
- **언어 A로 전환할 때 사용할 고정 응답**: 언어 A로 작성합니다.

#### DTMF Function

DTMF Function은 키패드 입력 수집, 검증, 시간 초과, 재시도 절차를 구성합니다. 화면에는 다음 설정 영역이 포함됩니다.

| **필드** | **설명** |
|-|-|
| Function 이름 | 사용자 정의 이름입니다. |
| Function 트리거 설명 | Function이 실행될 조건을 설정합니다. |
| 키패드 입력 결과를 임시 변수에 연결 | 키패드 입력 결과를 받을 임시 변수를 지정합니다. |
| Function 성공 시 고정 응답 | 여러 언어로 설정할 수 있습니다. |
| 키패드 입력의 “완료” 키 | 완료를 나타내는 키를 선택합니다. 기본값은 “#”입니다. |
| 키패드 입력의 “지우기” 키 | 지우기를 나타내는 키를 선택합니다. 기본값은 “\*”입니다. 이 기능은 켜거나 끌 수 있으며 기본값은 꺼짐입니다. |
| 키패드 입력 형식 검증 | 시스템이 입력 형식의 유효성을 판별할 때 사용합니다. 정규식으로 작성합니다. |
| 값 검증에 사용할 사용자 정의 Function | 기존 사용자 정의 Function Key를 추가하고, 이에 대응하는 임시 변수를 지정합니다. |
| 키패드 입력 시간 초과 설정 | 설정된 시간 동안 입력이 없으면 Function을 종료합니다. 기본값은 60초, 최댓값은 300초입니다. |
| 입력 시간 초과 시 고정 응답 | 여러 언어로 설정할 수 있습니다. |
| 키패드 입력 형식 오류 재시도 횟수 | 사용자가 입력한 내용이 형식 검증을 통과하지 못했을 때 재시도할 수 있는 최대 횟수입니다. 한도에 도달하면 Function이 종료됩니다. 기본값은 5회이며 1\~20회로 설정할 수 있습니다. |
| 키패드 입력 형식 오류 시 고정 응답 | 각 검증에서 사용할 응답입니다. |
| 최종 키패드 입력 형식 검증 실패 후 전화 전환 여부 | 예: 관련 전화 전환 설정을 입력합니다.  <br/>아니요: 형식 검증 실패 시 고정 응답을 설정합니다. |
| 키패드 입력 형식 검증 성공 시 고정 응답 | 여러 언어로 설정할 수 있습니다. |

 참고: 입력값의 실제 유효성을 최종 확인하려면 사용자 정의 Function을 통해 입력값을 외부 시스템으로 보내 검증해야 합니다.

#### 사용자 정의 Function 

레거시 사용자 정의 Function에서는 Function 기본 정보, 흐름 식별자, 변수를 설정해야 합니다.

##### 기본 정보

- **Function name**: 텍스트이며 필수 항목입니다.
- **Function 설명**: 텍스트이며 필수 항목입니다.
- **Flow 고유 식별자 (DAG ID)**: 흐름의 고유 식별자를 입력합니다.
- **Function 실행 시 고정 응답**: 텍스트입니다. 다국어 Agent는 언어별로 응답을 입력해야 합니다.

##### 변수 목록

변수 목록에는 다음 필드가 표시됩니다.

- 변수 이름
- key
- 데이터 유형
- 변수 유형: Function 변수 또는 전역 임시 변수
- 설명
- 작업: 편집 또는 삭제

전역 임시 변수는 편집할 수 없고 삭제만 가능합니다.
