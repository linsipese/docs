## 개요

Daisybell Agent Lab의 Agent Builder는 전화 및 대화형 업무를 위한 구조화된 Agent 구축 진입점으로, 기업의 Agent 구축 담당자, BPO 업체, 고객 구축 및 제공 팀을 대상으로 합니다.

실제 업무에서 하나의 Agent는 신원, 언어, 음성, 대화 흐름, 업무 지식, 데이터 필드, 변수, 도구 호출을 함께 다루는 경우가 많습니다. Agent Builder는 이를 하나의 구성 흐름으로 통합합니다. 먼저 Agent의 기본 정보와 업무 진입점을 정의하고, 언어·음성·전화 리소스·동시 실행 등 운영 조건을 설정합니다. 그런 다음 Script로 대화 동작을 구성하고 Skills, Tools, Knowledge, Fields, Variables를 조합해 업무 흐름을 설계합니다. 업무상 역할, 대화 전략, 실행 작업, 데이터 기록이 각각 명확한 위치에 있으므로 팀은 모든 로직을 관리하기 어려운 긴 Prompt 하나에 쌓아 두지 않고 모듈별로 Agent를 관리할 수 있습니다.

Agent Builder는 구축 과정이 실제 전화 업무의 제약을 반영하도록 설계되었습니다. 구축 담당자는 업무에 맞춰 기본 언어와 보조 언어를 정하고 언어별 음성 기능을 설정할 수 있으며, 전화 회선·아웃바운드 통화·전환 등 리소스 경계도 업무 설정에 반영할 수 있습니다. 대화의 업무 규칙은 Script와 재사용 가능한 Skills로 구성하고, 조회·전환·지식 검색·언어 전환·통화 종료·사용자 정의 업무 동작은 Tools와 Function으로 설정합니다. 도구의 입력·출력과 변수 매핑을 Agent 필드에 연결하면 주문 번호, 고객 등급, 처리 결과, 전환 상태 등을 구조화된 형태로 기록할 수 있습니다.

지식은 단순히 업로드한 뒤 모델에 맡겨 사용하는 것이 아닙니다. Agent Builder는 지식 베이스의 파일 관리, 파싱 결과 검토, Script 연결을 지원합니다. 이를 통해 팀은 제품 정책, 애프터서비스 약관, 기타 업무 자료를 관리 가능한 지식 자산으로 정리하고 어떤 업무 대화에서 이를 사용할지 지정할 수 있습니다. 본인 확인, 인증번호 입력, 민감 정보 처리가 필요한 시나리오에서는 도구와 변수 설정으로 검증·재시도·실패 처리·데이터 보호의 업무 경계를 정의할 수 있어, “먼저 검증한 뒤 실행한다”와 같은 규칙을 Agent의 실제 운영 설정에 반영할 수 있습니다.

Agent Builder를 사용하면 Agent를 시연용 대화 프로토타입에서 기업 업무에 실제로 적용할 수 있는 구성으로 발전시킬 수 있습니다. 구축 단계에서 Agent의 역할, 답변 근거, 도구 호출 시점, 결과 기록 방식, 전화 회선·언어·지식·데이터 제약 안에서 업무 대화를 완료하는 방법을 명확히 할 수 있습니다. 통합된 구조화 설정을 바탕으로 기업은 구체적인 업무에 맞는 관리 가능한 Agent를 구축하고, 실제 업무에 적용하고 운영하는 과정에서 Agent의 규칙·지식·실행 동작·데이터 기록을 지속적으로 관리할 수 있습니다.
