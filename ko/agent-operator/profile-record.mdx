![](/images/ko/agent-operator/profile-record/img-WB2zbZDI0oPvzVx6DhIjE7ZQpqc.png)

- Daisybell Agent Lab에 오신 것을 환영합니다. 이 플랫폼은 Agent를 통합 관리하고 관측·분석하는 작업 공간을 제공해 AI Agent의 업무 성과를 전반적으로 추적하고 개선하도록 돕습니다.
- 이 문서에서는 인바운드, 아웃바운드, 텍스트 대화, 웹 음성 등 Agent 유형별 상세 정보 확인 방법, 주요 데이터 대시보드 분석, 통화 상세 기록 확인, 업무 로그 및 사용자 정의 필드의 효율적인 관리 방법을 설명합니다.

---

### 1. Agent 기본 정보 (Profile)

Agent 상세 페이지 상단에서 Agent의 핵심 정보를 확인하고 관리할 수 있습니다.

- **기본 설정**: Agent 이름(최대 40자), 사용자 지정 아바타 업로드, 전용 Title, Agent 업무 유형, 사용자 정의 설명이 포함됩니다.
- **Agent 유형**: Agent에 연결된 전화번호를 표시합니다. Inbound(인바운드)와 Outbound(아웃바운드) 유형은 서로 다른 아이콘으로 구분합니다.

![](/images/ko/agent-operator/profile-record/img-Bf0Db3HCmoHdKKxuYilj6jV7pud.png)

### 2. 데이터 내역 (Data Summary)

Agent 유형별로 업무 시나리오에 맞는 다차원 데이터 대시보드를 제공합니다. 오른쪽 위의 시간 필터에서 원하는 기간을 선택할 수 있으며, 기본값은 당일 데이터입니다.

#### 인바운드 (Inbound) 및 웹 음성 (Webvoice)

- **총 통화 수**: 해당 기간에 성공적으로 종료된 통화(Finished) 수입니다.
- **평균 통화 시간**: 유효한 대화 한 건당 평균 소요 시간입니다.
- **통화 시간 분포**: 막대 그래프로 통화를 시간 구간별(예: 짧은 통화, 긴 통화)로 표시합니다.

![](/images/ko/agent-operator/profile-record/img-C8zRb0xRNowphFxOrWqjEexUpnf.png)

#### 아웃바운드 (Outbound)

- **작업 통계**: 해당 기간의 전체 작업 수와 완료된 작업 수를 표시합니다.
- **통화 개요**: 총 발신 수, 연결 수, 미연결 수(응답 없음)를 표시합니다.
- **핵심 전환 지표**: “전화 연결률”(연결 수 / 총 발신 수)을 자동 계산하고 평균 통화 시간과 통화 시간 분포를 막대 그래프로 제공합니다.

![](/images/ko/agent-operator/profile-record/img-MbYAbSviIoutb3x5zXLjfo5iprf.png)

#### 텍스트 대화 (Chatbot)

- **세션 데이터**: 전체 세션 수(Total Sessions)와 평균 대화 시간을 표시합니다.
- **인터랙션 깊이**: 전체 대화 턴 수(Total turns)와 턴 분포를 막대 그래프로 제공해 AI와 사용자의 상호작용 정도를 파악할 수 있습니다.

![](/images/ko/agent-operator/profile-record/img-T0s3bOmc1o8sR5xNdVOjqrcGpRd.png)

### 3. Outbound 유형 Agent 작업 및 기록 관리 (Records & Tasks)

#### 3.1 아웃바운드 작업 관리 (Task Records)

Outbound Agent에서는 작업 목록을 사용해 모든 아웃바운드 작업 진행 상황을 세밀하게 관리할 수 있습니다.

- **작업 상태 추적**: 작업 진행 상황을 실시간으로 모니터링하고 다음 상태를 확인할 수 있습니다: **시작 전(Not Started), 실행 중(Executing), 일시 중지(Paused), 종료됨(Terminated), 완료(Completed).**
- **동적 진행률 표시줄**: 진행률 표시줄에서 현재 발신 수가 전체 작업에서 차지하는 비율을 확인할 수 있습니다.
- **작업 제어**: 실행 중인 작업을 한 번의 클릭으로 일시 중지하거나 재개할 수 있습니다. 더 이상 진행할 수 없는 작업은 “종료”할 수 있습니다. 종료는 사용자가 직접 완료하는 작업이며, 한 번 실행하면 다시 진행할 수 없습니다.

![](/images/ko/agent-operator/profile-record/img-MZrGbcSrzoKn6gxSY00jItvvpmb.png)

![](/images/ko/agent-operator/profile-record/img-E4gebd63kofmj7xgpnOj0fTPpkf.png)

#### 3.2 통화 및 대화 기록 (Call & Chat Logs)

모든 유형의 인터랙션 이력이 상세 목록에 저장됩니다.

- **기본 필드 표시**: 기본적으로 시작 시간, 전화번호(해당하는 경우), 대화 시간, 대화 턴 수(Chatbot만 해당), 자동 생성된 대화 요약(Summary)을 표시합니다.
- **정확한 상태 추적**: 아웃바운드 기록에는 실제 실행 상태가 정확히 표시됩니다. 예를 들어 통화 완료(Completed), 결번(Notfound), 응답 없음(Noanswer), 연결 불가(Unavailable), 통화 중(Busy) 등이 있습니다. Busy는 상대 회선이 통화 중인 상태를 나타냅니다.
- **사용자 정의 필드 표시**: 이미 만든 Agent 필드를 추가하거나 숨길 수 있으며, 필드 순서를 드래그해 조정할 수 있습니다.

![](/images/ko/agent-operator/profile-record/img-Ex3IbeSc0oFlgjxXohpjrazTpmh.png)

- **필터 및 내보내기**：

  - 시간, 숫자, 텍스트, 열거형, 불리언 유형을 정확하게 필터링할 수 있고 여러 조건을 함께 적용할 수 있습니다.

  ![](/images/ko/agent-operator/profile-record/img-SOsHbqG4yoIYcExan85j79nMpGx.png)

  - 현재 필터 조건과 필드 정렬을 적용한 목록 데이터를 한 번의 클릭으로 Excel 파일로 내보내 오프라인에서 분석할 수 있습니다.

#### 3.3 필드 설정 및 작업 화면에서 편집 (Field Settings)

복잡한 업무 요구를 지원하기 위해 동적 필드 구성 기능을 제공합니다.

- **시스템 내장 필드 (Is System)**: 전화번호, 시작 시간, 종료 시간, 통화 시간, 요약, 상태 등의 핵심 지표를 시스템에서 자동으로 수집하며 삭제할 수 없습니다.
- **사용자 정의 업무 필드**: 작업 화면에서 텍스트, 열거형, 불리언 등의 사용자 정의 필드를 만들고 화면에서 수정할 수 있는지 여부와 기본값을 설정할 수 있습니다.
- **화면에서 빠르게 편집**: “작업 화면에서 수정 가능” 권한이 부여된 사용자 정의 필드는 운영자가 기록 목록에서 바로 수정할 수 있어 데이터를 빠르게 정정할 수 있습니다.

### 4. 대화 기록 상세 페이지 (Record Detail)

상세 목록에서 “상세 내역”을 클릭하면 단일 인터랙션을 자세히 확인할 수 있는 페이지가 열립니다.

- **정밀한 기록 재현**: 대화 기록을 원활하게 재현하고 정확한 인터랙션 시간을 확인할 수 있습니다. 시간은 초 단위로 올림 처리합니다.
- **음성 재생**: 음성 인터랙션에는 전체 오디오를 재생할 수 있는 컨트롤이 제공됩니다.
- **상담원 전환 표시**: 통화 중 상담원이 인계받으면 화면에 명확한 전환 구분선이 표시되고, 이후 상담원(Transfer Speaker)과 최종 사용자 간 전체 대화가 이어집니다.
- **도구 호출 및 노드 전환:** 실제 대화 중 Agent는 정의된 로직에 따라 도구를 호출합니다. 여러 노드로 구성된 Script는 조건에 따라 노드를 전환하며, 이러한 과정은 대화 기록 오른쪽의 카드로 시각화됩니다.

  - 현재 제공되는 시각화 카드는 다음과 같습니다.
  
    - 노드 전환
    - 전화 트리 전환
    - 도구 호출
    
      - 통화 전환 도구
      - 가이드 모드 도구
      - 지식 검색 도구
      - 통화 종료 도구
      - 언어 변경 도구
      - 사용자 정의 도구
    - 임시 변수값 변경
    - To do items
