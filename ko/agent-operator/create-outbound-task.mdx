---
title: "아웃바운드 Agent — 호출 태스크 생 (Create Outbound Task)"
---

기업이 아웃바운드 업무를 효율적으로 시작할 수 있도록 Daisybell은 발신 작업 생성 및 데이터 가져오기 기능을 개선했습니다. 시스템은 자주 사용되는 다양한 리드 입력 형식을 자동으로 인식하고 보정해 형식 오류로 인한 가져오기 중단을 크게 줄입니다.

---

### 1. 새 발신 작업 생성 (Create Task)

Daisybell 작업 공간에서 새 발신 작업을 시작할 때 관리자는 다음 세 가지 핵심 영역만 설정하면 됩니다.

#### 1.1 기본 정보 입력 (Basic Information)

- **작업 이름 (Task Name)**: 설정 창을 열 때 작업 이름을 입력하는 필수 텍스트 필드가 표시됩니다.
- **업무 Script 선택 (Script)**: 발신 작업에 연결할 AI 응대 Script를 지정합니다. 현재 작업 공간에 사용 가능한 Script가 하나뿐이면 기본으로 선택되며, 가장 최근에 생성된 Script 버전이 우선 연결됩니다.
- **호출 우선순위 (Priority)**: 호출 대기열에서 작업이 처리될 우선순위를 결정합니다. 기본값은 **Normal (일반)** 입니다.

![](/images/ko/agent-operator/create-outbound-task/img-HrVjb3ej6o6TLYxjS2wjdJiipKd.png)

#### 1.2 호출 시간대 설정 (Call Time Setting)

발신 작업을 요일별로 어느 시간대에 자동 발신할지 세밀하게 설정할 수 있습니다.

- **15분 단위 설정**: 설정 페이지에는 월요일부터 일요일까지의 `08:00 - 20:00` 시간대가 시각화된 표로 표시됩니다. 최소 설정 간격은 15분이며, 화면에 스크롤이 제공됩니다. 기본적으로 `08:00` 보기에 맞춰 표시됩니다.
- **빠른 시간대 설정 (Select Preset)**: 시스템에서 미리 설정한 업무 시간대를 한 번의 클릭으로 적용할 수 있습니다. 설정을 적용하면 매일의 호출 시간대가 `08:00` 부터 `20:00` 까지로 지정됩니다.

![](/images/ko/agent-operator/create-outbound-task/img-QlyGb8LcsozrFjxAVUyjumaJpLg.png)

### 2. 아웃바운드 리드 데이터 가져오기 및 템플릿 기준

![](/images/ko/agent-operator/create-outbound-task/img-PMVcbxrmdo19SmxggdijfXoSpJh.png)

표준 데이터 템플릿을 사용해 대량의 아웃바운드 리드를 가져올 수 있습니다.

#### 2.1 외부 리드 필드 기준 (Fields Specification)

가져오기 파일에서 사용할 수 있는 필드(Fields)는 Agent 필드 관리에서 미리 “외부 가져오기 허용”을 선택한 사용자 정의 필드와 일치해야 합니다.

![](/images/ko/agent-operator/create-outbound-task/img-GccAbLKaFo4N9jx66GljSkHrpHf.png)

- **필수 항목**: 가져오는 열 중에 **필수 입력 항목은 전화번호(Phone)입니다.** 이름, 나이, 성별, 비고 등 나머지 사용자 정의 필드는 비워 두거나 빈 값으로 입력할 수 있습니다.
- **최대 필드 수**: 한 번에 업로드하는 표에는 최대 **20개**의 필드 열이 포함될 수 있습니다. 20개를 초과하면 시스템이 초과 열을 자동으로 무시합니다.
- **데이터 형식 기준**:

  - **텍스트 유형**: 셀 하나에 최대 1,000자까지 입력할 수 있습니다.
  - **숫자 유형**: 소수점 이하 최대 3자리까지 지원합니다.
  - **날짜 및 시간 유형**: 입력값은 표준 형식(예: `YYYY-MM-DD HH:mm:ss`)을 따라야 합니다.
  - **불리언 유형**: 시스템은 True 또는 False를 해당 업무 판단 값으로 자동 변환합니다.
  - **열거형 유형**: 입력 텍스트는 작업 공간에 미리 설정된 사용 가능한 열거 값과 정확히 일치해야 합니다.
  - **문자 형식 기준**: 정확한 파싱을 위해 파일의 모든 리드 데이터는 가능한 한 반각 문자로 입력하세요.

#### 2.2 Excel 템플릿 다운로드

- **구조 및 순서 기준**：**다운로드한 템플릿은 Agent 필드 설정에 따라 생성됩니다. 반드시 템플릿에 맞춰 내용을 입력하고 헤더 필드는 수정하지 마세요.**

#### 2.3 업로드 제한

현재 시스템은 확장자가 **`.xlsx`** 인 표준 Excel 파일만 가져올 수 있습니다. 파일을 업로드 영역에 놓으면 화면에서 기본 검증을 수행하며, 검증에 실패한 파일은 차단되고 업로드 실패 안내가 표시됩니다.

- 파일 하나의 크기는 **50MB**를 초과할 수 없습니다.
- 파일 하나에 포함된 전체 데이터 행 수는 전체 데이터 행 수는 10,000행 미만이어야 한다. 10,000행을 초과하면 차단 안내가 표시되고 업로드가 중단됩니다.

### 3. 데이터 정규화

고객마다 입력 습관이 달라 업로드에 실패하는 문제를 줄이기 위해 백엔드에서 데이터 정규화(Normalization)를 수행합니다.

#### 3.1 전화번호 정규화

필수 전화번호 필드는 데이터를 읽을 때 자동으로 정규화됩니다.

- **전각 및 반각 숫자 자동 변환**: 입력한 중국어 또는 일본어 전각 숫자(예: `０１２３...` )를 표준 반각 숫자(`0123...`)로 변환합니다.
- **2단계 다이얼링 지원**: 저장 형식은 2단계 다이얼링 명령을 지원하며, 전화번호에 DTMF 제어 문자와 특수 키 기호(예: `+1234<dtmf>2367*#213`)를 포함할 수 있습니다.
- **잘못된 문자 차단**: 전화번호 셀에 영문자(`a-z, A-Z`) 또는 표준 통신 기호 외의 특수 기호( `@` 등)가 포함되면 업로드를 차단합니다.
- **중복 및 값 존재 여부 검증:** 정규화된 전화번호는 빈 값일 수 없으며, 현재 가져오기 파일의 다른 행과 중복될 수 없습니다.

#### 3.2 날짜 및 시간 필드의 여러 형식 인식 (Datetime / Date)

시스템에 저장할 때는 모두 표준 `YYYY-MM-DD HH:mm:ss` 형식으로 변환합니다.

### 4. 데이터 미리보기 및 셀 편집 (Preview & Edit)

기본 검증을 통과하면 온라인에서 데이터를 수정할 수 있습니다.

![](/images/ko/agent-operator/create-outbound-task/img-WdFXbTeVAo6EVhxsDMSjy84ip45.png)

- **파일 데이터**: 파일 전체 행 수(Total), 형식이 올바른 행 수(Correct), 오류가 있는 행 수(Errors)를 표시합니다. 오류 행 번호의 예: `*1, 3``번 열에 오류 발생`
- **데이터 상태 시각화**:

  - **오류 셀 (Errors)**: 잘못된 문자, 중복 번호, 전화번호 누락 등으로 검증에 실패한 셀은 배경색이 자동으로 **빨간색**
  - **빈 셀 (Empty)**: 필수 항목이 아닌 사용자 정의 필드에 값이 없으면 셀 배경색이 자동으로 **노란색**
- **데이터 필터**:**빈 셀이 있는 행 필터(Filter for rows with empty cells)** 및 **오류 행 필터(Filter for error rows)**
- **데이터 편집**

  - **유형에 맞는 편집기**: 작업 열에서 편집 아이콘을 클릭하면 시스템이 해당 열의 필드 유형(텍스트, 열거형, 불리언, 숫자 등)에 가장 적합한 셀 편집기를 표시합니다.
  - **기록 추가 및 삭제**: **'추가'** 버튼을 클릭해 첫 행 위에 새 빈 행을 삽입하고 데이터를 직접 입력할 수 있습니다. 삭제 버튼으로 잘못되었거나 손상된 데이터 행을 완전히 제거할 수도 있습니다.
- **가져오기 확인**: 파일 전체의 누락된 내용을 모두 채우고 오류 행 수가 0(Errors: 0)이 되어야 데이터를 제출할 수 있습니다.
