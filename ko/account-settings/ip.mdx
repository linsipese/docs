---
title: "로그인 IP 보안 설정 및 로그인 로그"
---

기업 작업 공간(Workspace)의 데이터 보안을 위해 Daisybell Agent Lab에서는 콘솔 로그인 IP 허용 목록을 설정할 수 있습니다. 접속 출처를 엄격하게 통제하여 승인되지 않은 외부 네트워크의 접근을 효과적으로 차단할 수 있습니다.

이 문서에서는 신뢰할 수 있는 IP 허용 목록을 설정하고 보안 로그인 로그를 확인하는 방법을 설명합니다.

---

### 1. 기능 개요 및 적용 범위

- **적용 대상**: IP 제한 정책은 현재 작업 공간의 관리자(Admin)와 모든 하위 계정(Sub-users)에 전역 적용됩니다.
- **데이터 보존**: IP 허용 목록 기능은 기본적으로 꺼져 있습니다. 기능을 일시적으로 꺼도 이미 설정한 IP 목록은 보존되며, 다시 켜면 그대로 적용됩니다.
- **페이지 및 기능**: 현재 작업 공간의 Sub-user 계정에는 신뢰할 수 있는 IP 허용 목록을 설정하거나 보안 로그인 로그를 확인할 권한이 없습니다.

---

### 2. 신뢰 IP 허용 목록 설정(Trusted IP Whitelist)

![](/images/ko/account-settings/ip/img-AEs6bkIQco4CVIxRCUVjn8cUpid.png)

`Settings → Login IP Security Settings 페이지에서 접속 제어 정책을 관리할 수 있습니다.`

![](/images/ko/account-settings/ip/img-BUQrb9VOpopcwMxJzQnjDiPnprg.png)

#### 2.1 현재 네트워크 원클릭 추가(Quick Add)

시스템은 현재 네트워크의 공인 IP 주소와 위치(국가·도시)를 자동으로 확인합니다. 처음 설정을 활성화할 때는 **Add To Whitelist**를 먼저 클릭하여 현재 네트워크를 허용 목록에 추가하는 것이 좋습니다. 설정 오류로 본인 계정이 차단되는 상황을 방지할 수 있습니다.

![](/images/ko/account-settings/ip/img-MadMbfqmvoQEGDxPp6ujRYClpXc.png)

#### 2.2 IP 또는 네트워크 규칙 직접 추가

접속을 허용할 출처를 직접 입력할 수 있습니다. 단일 IP 주소와 CIDR 네트워크 대역(예: `198.51.100.0/24`)을 지원하며, 작업 공간마다 보안 규칙을 최대 20개까지 설정할 수 있습니다.

![](/images/ko/account-settings/ip/img-LMtIbbZ4soS6uoxmXIujYaJGpec.png)

잘못된 설정으로 서비스를 이용할 수 없게 되는 일을 방지하기 위해 입력값을 검증합니다.

- **시스템 자동 차단 (Error Blocked)**: 시스템 루프백 주소(예: `127.0.0.1`), 브로드캐스트/멀티캐스트 주소(예: `255.255.255.255`), 유효하지 않은 IPv4 형식 또는 목록에 이미 등록된 중복 항목을 입력하면 Error Blocked가 표시되고 저장할 수 없습니다.
- **고위험 설정 경고 (Risk Warning)**:

  - **사설 네트워크 IP**: 사설 네트워크 주소(예: `192.168.0.0/16`)를 입력하면 플랫폼에서 로컬 네트워크 주소를 식별할 수 없다는 경고가 표시됩니다. 그대로 저장하면 로그인하지 못할 수 있으므로 올바른 공인 출구 IP인지 확인해야 합니다.
  - **와일드카드 IP**: `0.0.0.0/0`을 입력하면 모든 IP의 로그인을 허용하는 설정이며, IP 허용 목록 제한 기능이 사실상 무력화된다는 경고가 표시됩니다.

#### 2.3 허용 목록 관리

IP를 추가하면 전용 라벨로 네트워크가 구분되어 표시됩니다.

- **Current IP**(녹색): 현재 사용 중인 네트워크 주소를 나타냅니다.
- **Private IP / Wildcard IP**(노란색): 접근 위험이 있거나 허용 범위가 지나치게 넓은 사설 네트워크 또는 와일드카드 네트워크를 나타냅니다.

목록에 등록된 규칙은 언제든지 편집하거나 삭제할 수 있습니다. 현재 접속 중인 IP(Current IP) 또는 목록의 마지막 항목을 삭제하려고 하면 오입력을 방지하기 위한 재확인 팝업이 표시됩니다.

### 3. 로그인 로그(Login Log)

`Settings` → `Login Log` 페이지에서 작업 공간의 관리 접속 기록을 감사해 계정 보안을 유지할 수 있습니다.

![](/images/ko/account-settings/ip/img-UdoYbAq4AoUGV4x135HjgD5xp2c.png)



- **기록 방식**: IP 허용 목록 기능의 활성화 여부와 관계없이 시스템은 콘솔 로그인 활동을 정상적으로 기록합니다. (참고: 비밀번호 또는 계정 오류 등 일반적인 로그인 실패는 기록하지 않습니다.)
- **로그 필드**: 로그는 최신순으로 정렬되며, 로그인 시간(YYYY-MM-DD HH-MM-SS), IP/CIDR 주소, 작업 계정, 위치(도시·국가), 접속 상태를 확인할 수 있습니다.
- **이상 추적**: IP 허용 목록 위반으로 차단된 로그인은 빨간색 `Failed`로 표시되고, 정상 로그인은 녹색 `Success`로 표시됩니다. 기록 대상은 현재 작업 공간의 Admin 및 Sub-user 계정입니다.



---

### 4. 접속 거부(Access Denied)

- 로그인 후 작업 화면 페이지를 요청할 때나 로그인하지 않은 상태에서 로그인 페이지에 접근할 때, 접속 IP가 허용 목록에 없으면 시스템이 프런트엔드에서 접속을 차단합니다.
- 시스템은 느낌표 아이콘이 있는 **접속 거부(Access Denied)** 경고 창과 '현재 네트워크는 이 계정에 액세스할 권한이 없습니다. 신뢰할 수 있는 네트워크로 변경하거나 관리자에게 문의하세요.'라는 안내를 표시해 승인되지 않은 접속을 즉시 차단합니다.
