## 컨텍스트 테스트 세트

Context Test Set은 테스터가 모든 Script Version 테스트에서 저장한 컨텍스트 항목을 모아 둔 세트입니다.

모든 Script 버전의 텍스트 테스트에서 “Save Context” 기능으로 저장한 항목을 목록에서 확인할 수 있습니다.

![](/images/ko/test-center/context-test-set-backtest/img-V91fbl9u4oeKmOxV2rljtaaTpYg.png)

“미리 보기”를 클릭하면 테스트 세트 항목의 상세 정보를 확인할 수 있습니다.

![](/images/ko/test-center/context-test-set-backtest/img-DJWSbf2qNoMSlJx6Sj7j5ZH0pRd.png)

백테스트 (Backtest)

![](/images/ko/test-center/context-test-set-backtest/img-SwBwbEgGJopE0bxURKIj9Nx6pFe.png)

Context Test Set 창에서 항목을 선택하고 “Backtest”를 클릭하면 현재 Script Version으로 백테스트할 수 있습니다. 클릭하면 테스트가 자동으로 시작되고 결과가 생성됩니다.

![](/images/ko/test-center/context-test-set-backtest/img-OfHlbguI9oinrGxxY2JjOvVapdf.png)

테스트 결과에는 선택한 항목을 이전 대화 맥락으로 사용해 AI Agent가 다음 턴에 생성한 응답이 포함됩니다.

![](/images/ko/test-center/context-test-set-backtest/img-LPFzbS8MqowYCkxKAqPjiL7Ipoh.png)

결과가 보고서로 표시됩니다. 각 테스트가 예상에 부합하는지(Pass 또는 No Pass) 직접 선택한 뒤 “Save Result”를 클릭하면 테스트가 저장됩니다.

저장된 테스트 결과는 Script Version Detail Page의 목록에서 확인할 수 있습니다.

![](/images/ko/test-center/context-test-set-backtest/img-WKDvbFvp1o7c9fxO1UsjohNmpag.png)

모든 “백테스트” 결과는 “백테스트 기록” 탭에서 확인할 수 있습니다.

![](/images/ko/test-center/context-test-set-backtest/img-G6BabdaOVohemexYOYljkun2pDf.png)
