#### 스크립트 버전 편집 및 배포
- 현재 스크립트에 생성된 모든 버전의 목록입니다. 항목을 클릭하면 스크립트 Version Detail Page로 이동합니다.
- Action（Admin-user Only）

  - 공개(Release): “생성(Built)” 상태의 스크립트 버전을 “공개됨(Released)” 상태로 변경합니다. 공개(Release)하면 현재 버전을 만들기 전에 생성된 동일 계층의 “생성(Built)” 상태 스크립트 버전은 접혀서 해당 버전의 하위 목록으로 표시됩니다.
  - 게시(Publish): “공개됨(Released)” 상태의 스크립트 버전을 게시(Publish)하여 생산 환경에 올립니다.이미 “게시됨(Published)” 상태인 버전이 있으면 새 버전이 이를 대체합니다.
</column>
