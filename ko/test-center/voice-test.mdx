---
title: "음성 테스트 (Voice Test)"
---

<grid>
<column width-ratio="0.500000">
**1. 장치 설정**  
테스트 전에 테스트 화면 상단의 **설정** 에서 테스트 장치를 설정하세요. 오디오 입력 또는 출력 장치가 올바르게 설정되지 않으면 테스트에 영향을 줄 수 있습니다.
</column>
<column width-ratio="0.500000">
![](/images/ko/test-center/voice-test/img-1.png)
</column>
</grid>



<grid>
<column width-ratio="0.500000">
**2. 환경 설정** 테스트 페이지 오른쪽의 **설정** 에서 음성 모델, 언어 기본 설정, 오디오 파라미터를 구성하고 필요한 API 도구 세트를 연결합니다.
- 테스트를 시작하기 전에 Agent 필드(“Is system” 및 “Custom” 필드 포함)와 임시 변수에 사용할 값을 설정합니다.
- '사용자 정의 도구(Customized Tools)'에서 사용할 API(테스트 샌드박스 또는 프로덕션 API)도 설정할 수 있습니다. 현재는 사용할 수 없습니다.
</column>
<column width-ratio="0.500000">
![](/images/ko/test-center/voice-test/img-2.png)
![](/images/ko/test-center/voice-test/img-3.png)
</column>
</grid>

<grid>
<column width-ratio="0.500000">
**3. 실시간 테스트** 녹음 버튼을 클릭하고 마이크에 테스트 문장을 말합니다. 시스템이 오디오를 실시간으로 수집하고 처리합니다.
</column>
<column width-ratio="0.500000">
![](/images/ko/test-center/voice-test/img-4.png)
</column>
</grid>

<grid>
<column width-ratio="0.500000">
**4. 테스트 평가 및 저장**
테스트 내용을 미리 본 다음 현재 테스트를 저장하고 평가해야 합니다. 저장한 테스트는 스크립트 버전 상세 목록에서 확인할 수 있습니다.
</column>
<column width-ratio="0.500000">
![](/images/ko/test-center/voice-test/img-5.png)
</column>
</grid>
