title: "스크립트 버전 상세"

**스크립트 버전 상세 내역 페이지에서 해당 버전의 상세 정보와 구성 정보를 확인할 수 있습니다. 해당 버전의 모든 테스트 기록은 테스트 기록 목록에 표시됩니다.**

<grid>
<column width-ratio="0.500000">
#### 버전 정보 (Version Info)
- 스크립트 버전의 이름, 버전 번호, 상태, 생성자, 생성 시각을 표시합니다.
- 게시된(Published) 버전인 경우 게시자와 게시 시각도 표시됩니다.
</column>
<column width-ratio="0.500000">
![](/images/ko/test-center/script-version-detail/img-AHNrbMvDEo7QXmxtc4WjWTispIb.png)
</column>
</grid>

<grid>
<column width-ratio="0.500000">
#### 버전 구성 상세 (Config Details)
- '설정 상세'를 클릭하면 현재 AI Agent 기본설정 정보 창이 열립니다. 모든 설정은 Agent Builder에서 저장한 구성 스냅샷이며 다음 항목을 포함합니다.

  - Background Sound (배경음 설정)
  - Max Duration (최대 통화 시간)
  - Turn Detection (발화 완료 여부 판단)
  - Language Configuration (언어 설정)
  - Agent Fields (Agent 필드)
  - Temporary Variables (임시 변수)
</column>
