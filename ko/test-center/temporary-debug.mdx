---
title: "디버깅 기능"
---

대화 테스트에서 AI 응답이 기대와 다르더라도 새 `스크립트` 버전을 배포하거나 생성할 필요가 없습니다. 별도의 샌드박스 디버그 패널에서 `프롬프트`을 실시간으로 조정하고 `Tools` 의 트리거 설명 프롬프트를 수정해 한 번의 클릭으로 단일 턴을 검증할 수 있습니다.

---

### 1. 기능 개요

복잡한 대화 인터랙션을 테스트할 때 AI Agent를 미세 조정하려면 프롬프트나 도구 트리거 설명을 자주 수정해야 합니다. 기존에는 “스크립트 수정 - 버전 저장 - 재테스트” 절차를 거쳐야 해 단계가 많았습니다.

**임시 Debug** 는 가벼운 즉시 디버깅 공간을 제공합니다. 현재 대화 맥락을 유지하면서 대화 흐름의 원하는 턴을 바로 디버깅하고, 기본 시스템 프롬프트나 도구(Tools) 트리거 설명을 임시로 수정할 수 있습니다. 여러 결과를 동시에 생성하는 기능도 지원합니다.

---

### 2. 임시 Debug 시작

특정 대화 턴을 디버깅하려면 다음 단계를 따르세요.



1. **대상 대화 찾기**대화 상세 정보로 이동해 현재 텍스트 테스트에서 조정하거나 분석할 사용자 응답 말풍선을 찾습니다.
2. **Debug 패널 열기**말풍선 위에 마우스를 올린 뒤 왼쪽에 나타나는 `Debug` 버튼을 클릭합니다.

![](/images/ko/test-center/temporary-debug/img-RJRxbs1dpoZWdlxSJukj4jyCpHf.png)



---



### 3. 디버그 패널의 주요 설정



Debug 패널을 열면 작업 공간에 해당 대화 턴의 전체 실행 설정이 표시됩니다.

![](/images/ko/test-center/temporary-debug/img-QPqfbRqCkosnQHxTOUQjDeycptg.png)

**기능 모듈**

| 모듈 | 기능 설명 | 편집 가능 | 설명 |
|-|-|-|-|
| **현재 턴의 사용자 입력** | 현재 턴에서 사용자가 AI Agent에 보낸 원본 텍스트를 표시합니다. | 읽기 전용 | 시나리오 재현 |
| **프롬프트 텍스트 입력란** | 현재 턴의 전체 입력 프롬프트를 표시합니다. | 예 | Main 프롬프트 |
| **Tools 설정 영역** | 현재 환경에 연결된 모든 `Tools` 설정란을 동적으로 불러와 표시합니다. 연결된 도구 수에 따라 항목 수가 달라집니다. | 예 | 오른쪽 위에 `tool type` 레이블(예: `Instruction Mode` )이 표시됩니다. |

#### 프롬프트 변경 사항 비교

`프롬프트` 또는 도구 설명을 수정한 뒤 `Diff` 기능으로 변경 내용을 빠르게 확인할 수 있습니다.



### 4. 디버그 결과 생성

프롬프트 `프롬프트` 또는 `Tools` 트리거 설명을 수정한 뒤 오른쪽에서 Agent를 실시간으로 실행해 출력 품질을 분석할 수 있습니다.

![](/images/ko/test-center/temporary-debug/img-WhP4bSNE5obHAjxtc0Ej4dB6pfe.png)

#### 4.1 여러 결과 일괄 생성

1. **생성 개수 설정**: `Results` 입력란에 동시에 생성할 결과 수를 입력합니다. `1 - 20` 개까지 설정할 수 있습니다.
2. **생성 실행**: 오른쪽 아래의 Generate 버튼을 클릭해 해당 개수만큼 Reply 선택지를 생성합니다.

### 5. 텍스트 테스트 세트 업로드 지원
