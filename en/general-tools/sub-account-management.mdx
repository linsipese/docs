title: "Sub-account Management"
---

### Select “User Management” from the left navigation menu to open the sub-account creation and management page.

![](/images/en/general-tools/sub-account-management/img-1.png)

#### Create a Sub-account

- Select “Create New User.”

![](/images/en/general-tools/sub-account-management/img-2.png)

- Enter the information for the sub-account:

  - Username: The name displayed in Agent Lab.
  - Account: The email address must use the same domain suffix as the Admin account.
  - Security email: The system sends the initial password for the account being created to this security email address.

![](/images/en/general-tools/sub-account-management/img-3.png)

#### Sign in to a Sub-account

- Use the account (email address) entered by the Admin when creating the account.
- Use the initial password sent to the security email address.
- On the first sign-in to Agent Lab, the sub-account must reset its password. The account can be used normally after that.

#### Manage Sub-accounts

##### Reset a Sub-account Password

- The user's current password will become invalid.
- The system generates a new temporary password and sends it to the sub-account's security email address.
- After the reset, the user is forcibly signed out, and all unsaved changes are lost.

##### Configure Sub-account Permissions

- Grant the sub-account access to the relevant Agent details as needed for the business.

##### Disable or Delete a Sub-account (Admin Permission Required)

- Disable

  - The user immediately loses access to the system and can no longer sign in.
  - The account is forcibly signed out, and all unsaved changes are lost.
  - Account data is retained after the account is disabled.
- Delete

  - The user immediately loses access to the system and can no longer sign in.
  - The account is forcibly signed out, and all unsaved changes are lost.
  - Account data cannot be recovered after deletion.
