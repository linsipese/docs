title: "Export Center"
---

#### Use Export Center to download generated Agent conversation records.

- Click Export in the upper-right corner of the conversation record list on the Agent Details page to export all conversation records generated by the current Agent.

  ![](/images/en/general-tools/export-center/img-1.png)
- Download exported conversation files from Export Center.

![](/images/en/general-tools/export-center/img-2.png)

- In Export Center, records marked Completed are available to download. Wait for records marked Exporting to finish before downloading them.

Conversations

- Conversation records are exported as .xlsx files.
- Each file contains the same Agent fields shown in the Agent Details list, along with the complete conversation text.
