title: "Knowledge Base (Beta)"

Knowledge Base is the Agent Lab feature for providing and managing knowledge. Organize local documents by project. After you upload files, the system processes them asynchronously and extracts knowledge. You can then review, correct, and edit the extracted results, or add knowledge entries manually.



Extracted results are **Q&A pairs** type.

<column width-ratio="0.500000">
### Understanding the Knowledge Base Page
After you open **Knowledge Base** the project list appears on the left, and files in the selected project appear on the right.
- **Project List**: Shows project names and the number of files in each project, sorted from newest to oldest by creation time.
- **File List**: Shows the project name, status, upload date, number of knowledge entries extracted from each file, and available actions.

### Create and Manage Projects

Projects organize files. Create or select a project before uploading files.

#### Create a Project

1. Click **New Project**, to open the creation dialog. If no projects exist, this dialog opens automatically when you visit the Knowledge Base page.
2. Enter a name in **Project Name**. Names can contain up to 50 characters and must be unique. Leading and trailing spaces are removed.
3. Select the **Language** for knowledge extraction.
4. Select **Match Strategy**. The default is **Prioritized Match**.
5. Click **Create Project** to create the project.

![](/images/en/general-tools/beta/img-2.png)

#### Choose a Match Strategy

The match strategy determines how the system handles entries in the project marked as mandatory-match knowledge during retrieval.

| Strategy | How mandatory-match knowledge is handled | How regular knowledge is handled |
|-|-|-|
| **Prioritized Match**, the default strategy | If there is one mandatory-match entry, it is returned directly. If there are multiple entries, BM25 and vector similarity are used to return the most relevant one. | Handled through the standard retrieval process. |
| **Match All** | Returns all mandatory-match entries in the project without using BM25, vector retrieval, or an LLM to select among them. | Handled through the standard retrieval process. |

#### Delete a Project

1. Hover over the project name to display the delete icon.
2. Click the delete icon.
3. Confirm the deletion in the dialog.



### Check File Status

After you select a project, files are sorted by upload time from newest to oldest. The list shows 20 files per page by default. File search is not available in the Beta version.

The file status determines which actions are available.

![](/images/en/general-tools/beta/img-3.png)

| Status | Meaning | Available Actions |
|-|-|-|
| **Processing** | The file was uploaded successfully and is being processed. | No actions are available yet. The “…” button is disabled, and the details page cannot be opened. |
| **Extraction Failed** | Knowledge extraction was interrupted because of a parsing exception or error. | Retry processing; delete. |
| **Extracted** | The file has been processed. | View details; delete. |

For files with **Extract Failed** status, clicking Retry Processing restarts asynchronous processing, and the file status changes to **Processing**。

For files with **Extracted** status, click the file row or **View Details**, to open the knowledge extraction details page.

### Upload Files and Extract Knowledge

![](/images/en/general-tools/beta/img-4.png)

#### File Requirements

| Project | Requirement |
|-|-|
| Supported Formats | .pdf, .docx, .txt, .xlsx, .md |
| Maximum size per file | 10.00 MB |
| File Description (Prompt) | Up to 400 characters; leave blank to use the default. |

File Description guides the model's knowledge extraction. You can enter the file topic, a content summary, or specific extraction instructions.

#### Upload Procedure

1. Select the project for the file.
2. Click **Add Knowledge**, to open the **Add Knowledge file** dialog.
3. If needed, enter a **File Description**.
4. In the **Upload File** area, select a local file or drag it into the upload area.
5. Check the displayed file name and size.
6. Click **Upload & Process** to upload the file and start processing.



After a successful upload, the file enters the **Processing** status. Wait until it changes to **Extracted** to review and correct the extracted results. If the upload fails, an error appears on the page.

To replace a selected file, click the delete icon next to it, confirm in the dialog, and upload another file.

### View and Manage Knowledge Entries

After the file has been processed, open **View Details** to view the extracted structured knowledge. Entries appear as cards and support pagination.

#### Edit an Entry

1. Click Edit on the card.
2. Update the text as needed.
3. Save the changes on the card.

1. Click Delete on the card.
2. Confirm the deletion in the confirmation prompt.
