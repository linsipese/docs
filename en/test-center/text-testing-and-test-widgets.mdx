#### Text Test Widgets

> During a text test, use the available widgets to test and debug different aspects of the interaction.

<grid>
<column width-ratio="0.500000">
##### Import Context
- This feature is available only before you click the button to start the test.
- Select an existing context test set entry and click Import to add it to the current test.
- Before importing, click the button under Action to view the entry details.
</column>

<grid>
<column width-ratio="0.500000">
##### Upload Test Set
- Use this feature to import a large set of prepared test cases into the runner in a batch, instead of entering them one by one, for more efficient testing.
- You can add multiple user inputs and their corresponding expected Agent replies in a batch. Separate each input and expected reply with “|”, and enter one test case per line.
- Import from Excel or CSV is supported.
- Up to 50 test cases are supported per turn.
- After all results are generated, select one as the actual reply for the current test and continue testing.
- Test records are retained.
</column>

##### Save Context
- Save the conversation history up to the current turn as a context test set entry. You can then select it under Context.
- Preview the entry details when adding it, and assign the entry a name.
- Added entries appear in the Context Test Set.
</column>

<grid>
<column width-ratio="0.500000">
##### Debug
> Provides atomic analysis of an individual test case. Inspect LLM inputs in real time to quickly locate execution errors.
- If you are dissatisfied with an AI Agent's reply in a turn, click Debug to adjust the LLM input for that turn without changing the preceding context, then generate a new Agent reply.
- The Tool Trigger Prompt configured in the Script is displayed separately and can be edited in its own dialog.
- After editing the text, click Generate to produce batch replies.
- Click Upload Test Set to run a test set.
- Results generated by Debug cannot be saved.
</column>
