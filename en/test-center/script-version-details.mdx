title: "Script Version Details"

**The Script Version Detail page shows all details and configuration settings for a version. All test records for that version appear in the Test Records list.**

<grid>
<column width-ratio="0.500000">
#### Version Information
- Script archive name, version number, status, creator, and creation time.
- For a Published version, the publisher and publication time are also displayed.
</column>

#### Configuration Details
- Click Config Details to open a dialog showing the AI Agent's basic configuration. This is a snapshot of the settings configured in Agent Builder. It includes:

  - Background Sound
  - Maximum Call Duration
  - Turn Detection
  - Language Configuration
  - Agent Fields
  - Temporary Variables

#### Context Test Set

Click to open the list.

All context test set entries saved during tests of any version of the current Script are stored in this list.
