## Overview

- Before deploying an AI Agent to production, use the Daisybell Test Center to validate real conversations, edge cases, specific conditions, and batch scenarios. Thoroughly test and debug the Agent to help ensure it performs as expected in production.
- The Daisybell Test Center supports voice testing, text testing, and phone testing (in development), enabling rapid iteration and repeatable pre-release validation. After validation, release the final Script version and publish it to deploy the latest AI Agent version to production.
