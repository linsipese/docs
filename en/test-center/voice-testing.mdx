title: "Voice Testing"
---

<grid>
<column width-ratio="0.500000">
**1. Device Setup**  
Before testing, in the **Settings**, configure your devices. An incomplete audio input/output setup may affect the test.
</column>
<column width-ratio="0.500000">
![](/images/en/test-center/voice-testing/img-1.png)
</column>
</grid>



<grid>
<column width-ratio="0.500000">
**2. Environment Setup:**In the **Settings**, on the right side of the test page, configure the voice model, language preferences, and audio parameters, and associate the required API tool set.
- Before testing, set the required Agent fields (including “Is system” and “Custom”) and temporary variables.
- You can also set the API for Customized Tools (sandbox or production; not yet available).
</column>
<column width-ratio="0.500000">
![](/images/en/test-center/voice-testing/img-2.png)
![](/images/en/test-center/voice-testing/img-3.png)
</column>
</grid>

<grid>
<column width-ratio="0.500000">
**3. Run a Test in Real Time:**Click the record button and speak the test utterance into the microphone. The system captures and processes the audio in real time.
</column>
<column width-ratio="0.500000">
![](/images/en/test-center/voice-testing/img-4.png)
</column>
</grid>

<grid>
<column width-ratio="0.500000">
**4. Evaluate and Save the Test**
After reviewing the test content, save and evaluate it. Saved tests are listed on the Script Version Detail page.
</column>
<column width-ratio="0.500000">
![](/images/en/test-center/voice-testing/img-5.png)
</column>
</grid>
