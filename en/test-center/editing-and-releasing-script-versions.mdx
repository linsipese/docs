#### Edit and Release Script Versions
- The list shows all versions created for the current Script. Click a version to open its Script Version Detail page.
- Actions (Admin Users Only)

  - Release: Changes a Script version in the Built state to Released. After release, earlier sibling Script versions in the Built state—those created before this version—are collapsed into a nested list under the released version.
  - Publish: Publishes a Script version in the Released state to production. If another version is already Published, it is replaced by the newly published version.
</column>
