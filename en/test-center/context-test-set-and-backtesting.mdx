## Context Test Set

A context test set is a collection of context entries saved by testers during tests across all Script versions.

Entries saved with Save Context during text tests of any Script version are available in this list.

![](/images/en/test-center/context-test-set-and-backtesting/img-1.png)

Click Preview to view the details of a test set entry.

![](/images/en/test-center/context-test-set-and-backtesting/img-2.png)

Backtesting

![](/images/en/test-center/context-test-set-and-backtesting/img-3.png)

Select an entry in the Context Test Set dialog and click Backtest to run a backtest using the current Script version. The test starts automatically, and the results are displayed when it finishes.

![](/images/en/test-center/context-test-set-and-backtesting/img-4.png)

The results show the AI Agent's replies for the next turn, using the selected entry as context.

![](/images/en/test-center/context-test-set-and-backtesting/img-5.png)

The results are presented in a report. Testers can mark each item as Pass or No Pass. When all items have been reviewed, click Save Result to save the test.

Saved test results are available in the list on the Script Version Detail page.

![](/images/en/test-center/context-test-set-and-backtesting/img-6.png)

All backtest results are available on the Backtest Records tab.

![](/images/en/test-center/context-test-set-and-backtesting/img-7.png)
