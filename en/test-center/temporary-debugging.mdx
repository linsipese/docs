---
title: "Temporary Debugging"
---

During conversation testing, if the AI does not behave as expected, you can adjust the `Script` version in an isolated sandbox debugging panel—without publishing or creating a new one—then adjust the `Prompt`, edit the `Tools` trigger description prompt, and run a one-turn validation.

---

### 1. Overview

Fine-tuning an AI Agent during complex conversation testing often requires frequent changes to the Prompt or tool trigger descriptions. The traditional workflow—edit the Script, save a version, and test again—involves several steps.

**Temporary Debugging** provides a lightweight, immediate debugging workspace. It lets you debug any turn in place and temporarily modify the underlying system Prompt or tool trigger descriptions without disrupting the current context. You can also generate multiple result sets in parallel.

---

### 2. Open Temporary Debugging

To debug a single conversation turn, follow these steps:



1. **Locate the target conversation**: Open the conversation details and find the user message bubble to adjust or analyze in the current text test.
2. **Open the Debug panel**: Hover over the bubble and click `Debug` button on its left.

![](/images/en/test-center/temporary-debugging/img-H5wDbc5rEoZXr7xU1f4j7GajpT9.png)



---



### 3. Core Debug Panel Settings



After you open the Debug side panel, the workspace restores the full runtime configuration for that turn.

![](/images/en/test-center/temporary-debugging/img-T6hub1M8LoEL1AxurwOjUNeZp0e.png)

**Feature**

| Module | Description | Editable | Notes |
|-|-|-|-|
| **User input for current turn** | Displays the original text the user sent to the AI Agent in this turn. | Read-only | Scenario reconstruction |
| **Prompt text field** | Contains the complete input prompt for this turn. | Yes | Main Prompt |
| **Tools configuration area** | Dynamically loads and displays all `Tools` configuration fields associated with the current environment. The number of fields depends on the configured tools. | Yes | The top-right corner identifies the `tool type` label (for example, `Instruction Mode`). |

#### Prompt Diff Comparison

After editing the text in a `Prompt` or tool description, use `Diff` to review the changes:

![](/images/en/test-center/temporary-debugging/img-WUrFb23bGoXwMvxRCLIj2o7Qpeb.png)

---



### 4. Generate Debug Results

After adjusting the `Prompt` or `Tools` trigger description, run the Agent on the right and analyze the quality of its output.

![](/images/en/test-center/temporary-debugging/img-VmIxb7IEDoN5DmxA5SWjrsY6pIf.png)

#### 4.1 Generate Batch Results

1. **Set the number of results**: Enter the number of results to generate in parallel in the `Results` field (from `1–20` results).
2. **Generate results**: Click Generate in the lower-right corner to create the corresponding Reply options.

### 5. Test with an Uploaded Text Test Set

![](/images/en/test-center/temporary-debugging/img-VxeObLNx7oRfnbxs0FajRQ9Rp2c.png)

###### **Debug output is not saved**

- Because this is a sandbox for debugging only, temporary replies and trigger paths generated by test set runs **are not saved persistently.**
