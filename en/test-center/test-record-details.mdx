title: "Test Record Details"
---

<grid>
<column width-ratio="0.500000">
- Successfully saved tests can be viewed on the Test Record Details page.
- Test records include:

  - ACW (After-Call Work)
  - Summary Tags
  - Summary
  - Conversation Details
  - Tool and Node Switch Cards
  - Call Recording (Voice Test)
  - Analysis Trace
- `Tool Call and Node Switch`Preserves tool call and node switch fields. On the front end, the cards are combined into a collapsible section that displays the number of cards.
- The voice test player supports seeking, duration display, 5-second skip forward or back, play/pause, and MP3 download.
- You can star a record on the Test Record Details page. Starred records are pinned to the top of the record list.
- The right side of the Phone Test details page also includes a memo feature. All viewers can see any memo you add.
