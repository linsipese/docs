### 概要

企業における音声対話 Agent（Voice & Conversational Agent）の構築・導入では、開発・構築工程の分散、実行パラメータの調整の難しさ、外部業務システムとの接続の複雑さ、リリース後の品質監視の難しさといった課題に直面するのが一般的です。音声インタラクションのシナリオでは、リアルタイム性、安定性、サービス境界に対して非常に高い要件が求められます。従来方式では、分散したプロンプト管理、ハードコーディングされた回線連携、定量的な手段を欠くテストプロセスにより、レスポンスタイムの増大、応答文言の制御不能、業務連携の断絶などを招きやすくなります。

 

**Daisybell Agent Lab** は企業向け AgentOS（Agent オペレーティングシステム）の中核プラットフォームとして、音声・対話 Agent の研究開発から本番運用まで、ライフサイクル全体の管理という課題の解決を目指します。プラットフォームは、分散していた設定管理、ツール連携、知識ガバナンス、プロンプトエンジニアリングを統一された本番環境に集約し、企業が低コストかつ高い信頼性で Agent 業務を実装できるよう支援します。

 

### 実運用のクローズドループ

音声 Agent のリリースと運用には、厳密なエンジニアリングガバナンスとデータ検証が必要です。Daisybell Agent Lab は、品質ゲートとデータフィードバックを中核とする、ライフサイクル全体の管理モデルを確立しています。

 

構築 → 評価 → デプロイ → 評価 → 最適化 → 評価 → デプロイ

 

1. **構築（Build）：** 知識アセット、外部ツール、プロンプト、実行パラメータを統合し、Agent の初期構造設計と業務ロジックのオーケストレーションを完了します。
2. **リリース前評価（Pre-release Evaluation）：** Agent QA による自動回帰テストとシミュレーションシナリオの検証を通じて、応答文言のコンプライアンスとツール呼び出しの正確性を確認し、厳格なリリース可否判定基準を確立します。
3. **初回デプロイ（Initial Deployment）：** テストに合格したバージョンを本番環境へデプロイし、音声回線または通信チャネルに接続して、実際の業務トラフィックの処理を開始します。
4. **本番稼働後評価（In-production Evaluation）：** 実際の本番トラフィックに基づき、Evals（評価）モジュールでタスク完了率、有人対応への転送率、業務コンバージョン指標を抽出し、Agent Observer によって対話異常の原因を特定して、定性・定量評価を行います。
5. **戦略最適化（Optimization）：** 評価で見つかった知識の盲点、誤理解が発生する箇所、インタラクション遅延の問題に対して、Cerebra と Configuration でプロンプトの微調整、知識の補完、パラメータの調整を行います。
6. **回帰評価（Regression Evaluation）：** 最適化した反復バージョンを QA テストセットに再投入して比較検証を行い、新しい戦略が既知の問題を有効に解決すると同時に、既存の業務ロジックに回帰による機能不全を引き起こさないことを確認します。
7. **再デプロイ（Re-deployment）：** 検証に合格した新バージョンで本番環境の旧バージョンをシームレスかつスムーズに置き換え、サービスアップグレードの完全なクローズドループを一巡させ、Agent の能力を業務の進化に合わせて継続的に高めます。

このクローズドループにより、Agent の性能最適化は経験主導からデータ主導へと変わり、すべてのバージョン更新で追跡可能性と安定性を確保できます。

 

### Daisybell Agent Lab 機能アーキテクチャ

Daisybell Agent Lab には6つの中核機能モジュールが含まれ、Agent の構築、接続、ガバナンス、テスト、評価、オブザーバビリティ、人間と AI の協調に至る一連のフロー全体をカバーします：

#### 1. Agent Builder

- Agent の具体的な設定と能力の作成・編集を担い、その実行に必要な知識アセット、スキル設定、実行パラメータを継続的に保守します。Agent の実行パラメータと定型フレーズを一元管理し、変数定義、モデル温度（Temperature）、相づち語戦略、背景音、割り込み（Interruption）戦略などを含みます。

#### 2. Knowledge

- Agent が呼び出せる知識アセットを一元管理し、構造化知識ベースの保守をサポートします。また、Kadapter ツールを導入して、外部の非構造化知識を分解・クレンジング・構造化して取り込みます。企業知識を元文書からガバナンス可能なアセットへ変換し、検索・呼び出しの過程における知識の精度と保守性を確保します。

#### 3. Agent QA（品質ゲートと自動テスト）（Alpha バージョン稼働中）

- テキスト、音声などのマルチモーダルインタラクションに対する定性・定量デバッグツールを提供し、リリース判定テストと自動回帰テストをサポートします。Agent リリースの信頼できる品質判定基準を確立し、バージョン更新時に定量的なテスト結果の比較を提供することで、本番障害率を低減します。

#### 4. Evals（評価・指標管理センター）（正式リリース前）

- Agent の主要業務指標（KPIs）と品質評価基準を統一定義・設定・抽出します。二層評価メカニズムをサポートします：
- **リアルタイム指標抽出（Real-time Metrics）：** 対話中のトリガーイベント、関数呼び出し状態、ノード到達率をリアルタイムで捕捉します。
- **通話後の大規模言語モデルによる抽出（Post-call AI Extraction）：** 全通話の Transcript を対象にテキスト抽出と意図認識を自動化し、タスク完了率、有人対応への転送理由の原因帰属、コンプライアンスリスクの発生箇所などの定量基準を定義します。

非構造化の対話音声を構造化された業務 KPI データへ変換し、感覚に頼る調整の弊害をなくすことで、Agent の継続的な反復に客観的かつ定量的なデータ支援を提供します。

#### 5. Agent Operator（全プロセスのオブザーバビリティとタスク管理）（Beta バージョン稼働中）

- Agent の業務成果と実行プロセスを全方位で監視・診断し、4つの主要コンポーネントで構成されます：
- Dashboard（運用ダッシュボード）： 2種類の階層型可視化ダッシュボードを提供します：
- *標準ダッシュボード（Standard Dashboard）：* 呼量（Call Volume）、ブロック／自己解決率（Containment Rate）、平均処理時間（AHT）、ツール利用率、チャネル品質を監視します。
- *カスタム業務ダッシュボード（Custom Dashboard）：* Evals が抽出した業務 KPI を自由にグラフ化し、特定の業務シーンにおけるコンバージョン率と ROI を追跡できます。
- **Record Detail（通話アーカイブ）：** 通話内容を詳細に記録し、対話を1件ずつ確認して音声を再生できます。Agent とエンドユーザーのインタラクションの詳細をすべて記録します。
- **Analysis Trace（チューニング診断ビュー）（Alpha 内部テスト中、未公開）：** 単一インタラクションの各 Turn のテキスト、音声録音の波形、ASR 修正比較、モデルの初回トークン遅延（TTFT）、ツール呼び出しの Request/Response メッセージ、知識参照パスを展開します。
- **Task Manager：** アウトバウンド Agent のバッチ設定、同時実行数の上限管理、失敗時の再発信ポリシー、番号帯のコンプライアンスルーティングを提供します。

ブラックボックス運用のリスクを排除し、マクロな業務 KPI、中間レベルの安全・コンプライアンス、ミクロな個別通話ログに至るまで、全経路を透明に管理します。

#### 6. Human Agent Console（人間と AI の協調オペレーター・ワークベンチ）（正式リリース前）

- 「Human - AI の深い協働」のために特化して設計された、オペレーターとスーパーバイザーが一体となった業務プラットフォームです。従来のコールセンターにおける人手介入ポイントを再構成し、リアルタイム監視、随時介入、パフォーマンス評価、チケット処理へのシームレスな引き継ぎを含む、一連の協働フローを形成します：
- **リアルタイム多セッション監視（Real-time Multi-session Monitoring）：** オペレーターまたはスーパーバイザーはコンソール上で、複数経路の AI Agent が処理する並列通話を同時に監視し、Turn ごとのテキスト転写、感情変動のマーカー、スロット収集の進捗、潜在リスクのアラートをリアルタイムで確認できます。
- **シームレスな介入と随時引き継ぎ（Intervention & Human Takeover）：** 従来の「AI が転送を発動するまで受動的に待つ」方式を打破し、オペレーターは通話のリアルタイム状況と顧客感情に応じて、いつでも「ワンクリックで介入」または通話を全面的に引き継ぐ（Takeover）ことができます。システムは AI モードから人手モードへシームレスかつスムーズに切り替え、AI がエッジケースを理解できないことによる顧客の不満を防ぎます。
- **AI パフォーマンス評価と是正（AI Performance Evaluation & Feedback）：** オペレーターは監視または引き継ぎ中に、AI の現在の Turn における回答の正確性、応答文言の適切性、ツール呼び出し結果をリアルタイムでタグ付け・評価（Feedback）できます。評価・アノテーションデータは QA と Evals モジュールへリアルタイムにフィードバックされ、「人による是正が AI の進化を促す」好循環を形成します。
- **ACW コンテンツのシームレスな引き継ぎ（Seamless ACW Streaming）：** 通話の転送または引き継ぎ時に、AI が自動生成した対話要約（Summary）、収集済みの変数エンティティ、アフターコールワーク（ACW）チケットの下書きを、オペレーター画面へシームレスに引き継ぎます。オペレーターは顧客の背景情報を聞き直す必要がなく、重要事項を確認または補足するだけで迅速にアーカイブでき、平均処理時間（AHT）を大幅に短縮します。

従来のコールセンターがデジタル化・AI 化へ移行する業務ニーズに完全に対応します。「AI が高頻度の定型トラフィックを処理し、人がリアルタイムで監視・介入し、品質を是正する」混合サービスモデルにより、チームのサービス同時処理能力を数倍に高めつつ、高リスク・複雑なシーンでもサービス品質を確保し、スムーズで低リスクなアーキテクチャ刷新を実現します。

 

### まとめ

Daisybell Agent Lab は、標準化されたモジュール分割と「構築 → 評価 → デプロイ → 評価 → 最適化 → 評価 → デプロイ」という全ライフサイクル管理のクローズドループを通じて、複雑な音声・対話 Agent の開発を、管理・可観測・定量化が可能なエンジニアリングデリバリープロセスへ変換します。プラットフォームは、設定の分散、テスト・評価の欠如、システム連携コストの高さという課題を解決し、企業に堅牢な Agent 運用体制を構築するとともに、さまざまな業務シーンでの効率的な導入と継続的な進化を支援します。
