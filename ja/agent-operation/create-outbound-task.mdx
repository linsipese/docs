---
title: "Outbound Agent：発信タスクの作成"
---

企業がアウトバウンド業務をスムーズに開始できるよう、Daisybellでは発信タスクの作成とデータインポート機能を刷新しました。よくある入力形式の違いを自動で吸収・補正し、形式不備によるインポート中断を抑えます。

---

### 1. 発信タスクの作成（Create Task）

Daisybellのワークスペースで新しい発信タスクを作成する際は、次の主要項目を設定します。

#### 1.1 基本情報（Basic Information）

- **タスク名（Task Name）**：必須項目です。設定ダイアログを開いたら、テキストボックスにタスク名を入力します。
- **業務スクリプト（Script）**：発信タスクに適用するAIスクリプトを選択します。利用可能なスクリプトがワークスペースに1つだけの場合は、そのスクリプトが初期選択され、最新バージョンが適用されます。
- **発信優先度（Priority）**：発信キュー内でのタスクの優先度を指定します。初期値は **Normal（通常）**です。

![](/images/ja/agent-operation/create-outbound-task/img-ZtTbbpePooOnQnxvgnhjdDFepYg.png)

#### 1.2 発信可能時間帯（Call Time Setting）

発信タスクを自動実行する曜日と時間帯を設定できます。

- **15分単位の設定**：設定画面には、日曜日から月曜日までを対象とし、時間帯を `08:00 - 20:00` の範囲で表示する時間設定グリッドがあります。15分単位で設定でき、スクロールバーを備えています。初期表示は `08:00`です。
- **時間帯のプリセット（Select Preset）**：システムのプリセットをワンクリックで適用できます。適用後は、毎日の発信可能時間が `08:00`から`20:00`までに設定されます。

![](/images/ja/agent-operation/create-outbound-task/img-RlUBbm4HLofvapxUFCEjetbKpPL.png)

### 2. 発信リードのインポートとテンプレート仕様

![](/images/ja/agent-operation/create-outbound-task/img-MhNubiMGfonnWjxiV7JjWwFQp5b.png)

標準化されたデータテンプレートを使用して、多数の発信リードをまとめてインポートできます。

#### 2.1 外部リードのフィールド仕様（Fields Specification）

インポートファイルで使用できるフィールドは、Agentのフィールド管理で事前に「外部からインポート可能」に設定したカスタムフィールドに限られます。

![](/images/ja/agent-operation/create-outbound-task/img-HI9zb5q1MoflZuxFaaZjSWvdp6e.png)

- **必須項目**：インポートする列のうち、**「電話番号（Phone）」のみ必須です**。氏名、年齢、性別、備考などのカスタムフィールドは空欄にできます。
- **列数の上限**：1回のアップロードで扱えるデータ表の列数は最大**20**列です。20列を超える場合、超過分は読み込み時に自動的に無視されます。
- **データ形式の制約**：

  - **テキスト型**：1セルあたり最大1,000文字です。
  - **数値型**：小数点以下3桁まで入力できます。
  - **日時型**：次の標準形式に従って入力してください（例：`YYYY-MM-DD HH:mm:ss`）。
  - **ブール型**：TrueまたはFalseを対応する業務上の値として自動的に扱います。
  - **列挙型**：入力値は、ワークスペースで設定済みの選択肢と完全に一致する必要があります。
  - **文字種の指定**：正確に解析できるよう、リード情報はできるだけ半角文字で入力してください。

#### 2.2 Excelテンプレートのダウンロード

- **列構成と順序**：**ダウンロードしたテンプレートはAgentのフィールド設定に基づいて生成されています。必ずこのテンプレートを使用し、列見出しは変更しないでください。**

#### 2.3 アップロード制限

現在、インポートできるのは拡張子が **`.xlsx`** の標準Excelファイルのみです。アップロード領域にファイルを置くと画面上で基本チェックが行われ、条件を満たさないファイルはアップロードされず、エラーが表示されます。

- ファイルサイズは **50MB以下です。**
- 1ファイルあたりのデータ行数は**10,000行未満である必要があります**。10,000行を超える場合は警告が表示され、アップロードは中止されます。

### 3. データの正規化

入力方法の違いによるアップロードエラーを防ぐため、バックエンドでデータの正規化（Normalization）を行います。

#### 3.1 電話番号の正規化

必須項目の電話番号は、読み込み時に自動で正規化されます。

- **全角数字の半角変換**：入力された中国語または日本語の全角数字（例：`０１２３...`）は、標準的な半角数字（`0123...`）に自動変換されます。
- **2段階発信への対応**：電話番号にDTMF制御文字や特殊キー（例：`+1234<dtmf>2367*#213`）を含めた発信にも対応しています。
- **使用できない文字の検出**：電話番号のセルに英字（`a-z, A-Z`）や、一般的な電話記号以外の特殊文字（例：`@`）が含まれている場合は、エラーとして検出します。
- **必須入力と重複のチェック**：正規化後の電話番号は空欄にできません。また、同じインポートファイル内で重複する番号は登録できません。

#### 3.2 日時フィールドの複数形式への対応（Datetime / Date）

システムへの登録時には `YYYY-MM-DD HH:mm:ss`に統一されます。

### 4. データのプレビューと行内編集（Preview & Edit）

基本チェックの完了後、画面上でデータを修正できます。

![](/images/ja/agent-operation/create-outbound-task/img-NwYkbj5dIojgk6xaS07juiuUphd.png)

- **ファイルデータ**：ファイルの総行数（Total）、形式に問題のない行数（Correct）、エラーを含む行数（Errors）を表示します。エラー行は（例：`* Row 1, 3 have errors`）。
- **データ状態の色分け**：

  - **エラーセル（Errors）**：不正な文字、電話番号の重複、電話番号の未入力など、チェックでエラーになったセルは背景が自動的に**赤色になります**
  - **空欄セル（Empty）**：任意入力のカスタムフィールドが空欄の場合、セルの背景が自動的に**黄色になります**
- **データの絞り込み**：**Filter for rows with empty cells（空欄を含む行を絞り込む）** および **Filter for error rows（エラー行を絞り込む）**
- **データの編集**

  - **フィールド型に応じた編集**：操作列の編集アイコンをクリックすると、テキスト、列挙、ブール値、数値などのフィールド型に合わせた入力欄が表示されます。
  - **行の追加・削除**：**Add**をクリックすると先頭行の上に空行を追加できます。データを手入力して補完するか、削除ボタンで無効な行または不正なデータ行を削除してください。
- **インポートの確定**：ファイル内の未入力項目をすべて補い、エラー行数が0（Errors: 0）になった場合にのみ、データを登録できます。
