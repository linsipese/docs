- Daisybell Agent Labをご利用いただきありがとうございます。Agentの運用状況を一元的に管理・観測・分析できるワークスペースを提供し、AI Agentの業務パフォーマンスの把握と改善を支援します。
- 本ドキュメントでは、各種Agent（インバウンド、アウトバウンド、テキスト対話、Web音声）の詳細情報の確認、主要なデータダッシュボードの分析、通話記録の確認に加え、業務ログやカスタムフィールドを効率的に管理する方法を説明します。

---

### 1. Agentの基本情報（Profile）

Agent詳細ページの上部では、Agentの基本情報を確認・管理できます。

- **基本設定**：Agent名（最大40文字）、任意のアバター画像、専用タイトル（Title）、業務タイプ、カスタム説明を設定できます。
- **Agentタイプ**：Agentに紐づく電話番号を表示します。Inbound（受信）とOutbound（発信）はアイコンで区別されます。



![](/images/ja/agent-operation/profile-record/img-2.png)



---

### 2. 主要データダッシュボード（Data Summary）

Agentのタイプに応じて、業務に即した複数の指標をダッシュボードに表示します。右上の期間フィルターで対象期間を選択してください。初期表示は当日のデータです。

#### インバウンド（Inbound）／Web音声（Webvoice）

- **通話総数**：対象期間内に完了（Finished）した通話の件数です。
- **平均通話時間**：有効な通話1件あたりの平均時間です。
- **通話時間の分布**：通話時間を区間（短時間・長時間など）ごとに集計し、棒グラフで表示します。

![](/images/ja/agent-operation/profile-record/img-3.png)

#### アウトバウンド（Outbound）

- **タスク集計**：対象期間内のタスク総数と完了数を表示します。
- **通話概要**：発信件数、応答件数、未応答件数を表示します。
- **主要なコンバージョン指標**：応答件数を発信件数で割った「応答率」を自動計算し、平均通話時間と通話時間の分布を棒グラフで表示します。

![](/images/ja/agent-operation/profile-record/img-4.png)

#### テキスト対話（Chatbot）

- **セッションデータ**：セッション総数（Total Sessions）と平均対話時間を表示します。
- **対話の深さ**：対話ターン総数（Total turns）とターン数の分布を棒グラフで表示し、AIとユーザーの対話の深さを把握できます。

![](/images/ja/agent-operation/profile-record/img-5.png)

### 3. Outbound Agentのタスクと記録の管理（Records & Tasks）

#### 3.1 発信タスクの管理（Task Records）

Outbound Agentでは、タスクリストから発信タスクの進行状況を管理できます。

- **タスクステータスの追跡**：タスクの進捗をリアルタイムで確認できます。次のステータスに対応しています：**未開始（Not Started）**、**実行中（Executing）**、**一時停止（Paused）**、**終了（Terminated）**および**完了（Completed）**。
- **進捗バー**：発信済み件数とタスク総数を、進捗バーで確認できます。
- **タスクの操作**：実行中のタスクを一時停止または再開できます。継続できないタスクは「終了」できます。終了するとタスクは再開できません。

![](/images/ja/agent-operation/profile-record/img-6.png)



![](/images/ja/agent-operation/profile-record/img-7.png)

#### 3.2 通話・対話記録の詳細（Call & Chat Logs）

すべての対話履歴は詳細リストに記録されます。

- **基本項目の表示**：開始時刻、電話番号（該当する場合）、対話時間、対話ターン数（Chatbotのみ）、自動生成された対話概要（Summary）を初期表示します。
- **ステータスの詳細表示**：発信記録には、実際の処理状態を表示します。例：完了（Completed）、未使用番号（Notfound）、応答なし（Noanswer）、接続不可（Unavailable）、話し中（Busy）。Busyは相手の回線が通話中であることを示します。
- **カスタムフィールドの表示**：作成済みのAgentフィールドを追加・非表示にしたり、ドラッグ＆ドロップで表示順を変更したりできます。

![](/images/ja/agent-operation/profile-record/img-8.png)

- **フィルターとエクスポート**：

  - 日時、数値、テキスト、列挙、ブール値で絞り込めます。複数の条件を組み合わせることもできます。

  ![](/images/ja/agent-operation/profile-record/img-9.png)

  - 現在のフィルター条件と項目の並び順を反映したリストを、Excelファイルとしてエクスポートし、オフラインで分析できます。

#### 3.3. フィールド設定とワークスペース上での編集（Field Settings）

多様な業務要件に対応するため、フィールドを柔軟に設定できます。

- **システム項目（Is System）**：システムが自動取得する必須項目です。削除できません（着信番号、開始時刻、終了時刻、所要時間、概要、ステータスなど）。
- **業務用カスタムフィールド**：ワークスペースでテキスト、列挙、ブール値などのカスタムフィールドを作成し、画面からの編集可否や初期値を設定できます。
- **画面上での簡易編集**：「ワークスペースで編集可」に設定されたカスタムフィールドは、運用担当者が記録リスト上で直接修正できます。

![](/images/ja/agent-operation/profile-record/img-10.png)

### 4. 対話記録の詳細ページ（Record Detail）

詳細リストの「View Detail」をクリックすると、個々の対話を詳しく確認できます。

- **対話の詳細な再現**：対話の流れを途切れることなく再現し、対話時間を秒単位で切り上げて表示します。
- **音声の再生**：音声での対話では、音声プレーヤーで録音を再生し、内容を振り返ることができます。
- **有人対応への転送表示**：通話が有人対応に切り替わると、画面に転送位置を示す区切り線を表示します。転送後のオペレーター（Transfer Speaker）とユーザーの対話も、ひと続きの履歴として確認できます。
- **ツール呼び出しとノード遷移：**対話中、Agentは定義された業務ロジックに従ってツールを呼び出します。複数ノードで構成されたScriptでは、判定結果に応じてノードが切り替わります。これらの処理は、対話記録の右側にカード形式で表示されます。

  - 現在、次のカードを表示できます：
  
    - Node switch
    - Phone tree switch
    - Tool Calling
    
      - Call Transfer
      - Instruction mode
      - Knowledge query
      - Hang up
      - language switching
      - Customize
    - Temporary Variable Value Change
    - Todo Items Update
