## Agent実行トレースの分析

AI音声やテキストの対話体験を改善するには、各ターンの背後でシステムがどのように処理したかを把握することが重要です。Daisybellは、**開発者以外の方**（プロダクトマネージャー、導入支援担当者、テストエンジニア、導入企業の担当者）向けに、**Agent Analysis Trace（対話トレース分析）**を提供しています。専門知識がなくても視覚的に診断でき、システムの主要な処理を分析して、対話の遅延や異常が発生した箇所をすばやく特定できます。これにより、Agentの対話品質を総合的に改善できます。

---

### 1. 機能の位置づけとアクセス方法

- **機能の位置づけ**：対話フローにおけるシステムの処理を詳しく分析します。各インタラクションの内部状態を確認することで、業務上のボトルネックや障害箇所の特定を支援します。
- **アクセス方法**：Agent Detailの対話記録ページで、Conversation Record内の任意のAgentの発話バブルの下にある **Latency（所要時間）**ラベルをクリックすると、画面右側に分析パネルが開きます。

![](/images/ja/agent-operation/analysis-trace/img-UfHRbYDZDoxGywxRjL4j6tZ6pNc.png)

---

### 2. 全体診断指標（Global Metrics）

Analysis Traceを開くと、上部のダッシュボードに対象ターンの主要な全体指標が表示され、パフォーマンスの概要を把握できます。

![](/images/ja/agent-operation/analysis-trace/img-EOZab5UGeoffPfxPodwjWMG2pOg.png)

- **開始時刻（Start Time）**：対象ターンが開始した正確な時刻を記録します（形式：`YYYY-MM-DD HH:MM:SS`）。
- **総レイテンシ（Total Latency）**：**ユーザーが話し終えてからAIが発話を開始するまで**の時間（単位：ミリ秒／ms）です。性能の目安を色で示します（数値を10の位で切り上げて判定）：

  - **レイテンシ $\ge 2000\text{ms}$**：**黄色**
  - **レイテンシ $\ge 3000\text{ms}$**：**赤色**
- **Token消費量（Token Consumption）**：対象ターンにおけるすべての大規模言語モデル（LLM）呼び出しの累計Token数を表示します（$\sum\text{LLM}$）。
- **処理結果（Status）**：対象ターンの最終的な処理結果を、**成功（Success）**または**失敗（Failed）**で示します。

![](/images/ja/agent-operation/analysis-trace/img-PVUZbN7J3ogagrxgtUFjNCaopje.png)

### 3. プロセスのタイムライン（Processes Timeline）
処理時間の内訳を一目で確認できるよう、分析パネルの左側に複数のレーンからなるタイムラインを表示します。システム処理に関わる主要なサービスプロセスは、実行順に縦方向へ並びます。
- **処理時間バーの表示**：各プロセスを色付きのバーで表示し、開始点と終了点を実際のタイムスタンプに合わせます。
- **クリティカルパスの特定**：タイムライン上で重なり、交差、または連続するバーから、最も長い連続経路を特定します。この経路が全体のLatencyとして表示されます。
- T: 数値は、該当プロセスで消費されたToken数を示します。

### 4. 主要サービスコンポーネントの詳細（Component Breakdown）

パネルの右側には各サービスプロセスの詳細が表示されます。展開すると、音声入力から音声出力までのログ全体を確認できます。

#### 4.1 音声認識と発話完了判定（ASR & VAD）

音声の取得からテキスト変換までを扱います。総処理時間は次の3つの内訳で構成されます。

- **音声区間検出（VAD）**：ユーザーの発話終了を検出した時刻（Back Endpoint time）と、実際の発話時間（Actual duration）を表示します。
- **音声認識（ASR）**：ASRモデルの認識時間（Duration）と、認識結果のテキスト（Output）を表示します。
- **発話完了判定（Completeness Detection）**：モデルの呼び出し時刻（Model Call Time）、応答時刻（Model Return Time）、判定に用いる遅延の重みを記録し、ユーザーが話し終えたかどうかをシステムが正確に判断できるようにします。

  ![](/images/ja/agent-operation/analysis-trace/img-XuHpbbsopoMOTAxyNlEjmxUApUf.png)

#### 4.2 大規模言語モデルの処理（LLM Module）

AIの判断処理を可視化し、主要な実行データとコンテキストの流れを表示します。

- **実行パラメーター**：対象ターンで使用したモデル名（GPT-4oなど）、LLMの処理時間、1回のリクエストで消費したToken数を表示します。
- Input：
- Output：「Content」の内容を表示します。

![](/images/ja/agent-operation/analysis-trace/img-PRoRbGXZvojezLxHo9sjEVUHpMg.png)

#### 4.3 ツール呼び出し（Tool Calling）

Agentが外部システムを呼び出したり、特定の指示を実行したりする処理を追跡します。標準関数とカスタム関数（Function）の実行状態を確認できます。

- **各種ツールに対応**：ナレッジ検索（Knowledge query）、電話転送（Call Transfer／新旧バージョンの両方）、指示モード切り替え（Instruction mode）、切断（Hang up）、言語切り替え（Language switching）、業務用カスタムAPI（Customize）など、各種プラグインの呼び出しを記録します。
- **構造化ログ**：各Tool Callで実行された関数名（Function_name）、処理時間、JSON形式の入出力（入力パラメーターと戻り値）を表示します。

  ![](/images/ja/agent-operation/analysis-trace/img-VeNBb1ZiXohuVDxrULIj10jNpzg.png)

#### 4.4 音声合成の出力（TTS Module）

対話処理の最終段階として、テキスト読み上げの実行状況を表示します。

- **処理時間の追跡**：TTSモデルへのリクエストから、音声の最初のチャンク（First Wave Chunk）をシステムが受信するまでの合成時間を記録します。
- **読み上げテキストの確認**：音声合成の元となる入力テキスト（Input Text）を表示し、読み上げ内容が正しいか確認できます。

![](/images/ja/agent-operation/analysis-trace/img-NSlAb5kZOoHXP5xRUvdjt2x9pTd.png)
