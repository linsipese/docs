## コンテキストテストセット

Context Test Setは、テスト担当者が各Script Versionのテスト中に保存したContext項目を集めたものです。

Scriptの各バージョンで行ったテキストテスト中に「Save Context」機能で保存した項目は、すべてこの一覧で確認できます。

![](/images/ja/test-center/コンテキストテストセットとバックテスト/img-HDcnbQ8Seoq2jrxCO36jqwF5pV3.png)

「プレビュー」をクリックすると、テストセット項目の詳細を確認できます。

![](/images/ja/test-center/コンテキストテストセットとバックテスト/img-CJITbjnhyoEPwAxKUBKjXZ8spee.png)

バックテスト（Backtest）

![](/images/ja/test-center/コンテキストテストセットとバックテスト/img-AdPDbJVMFoyQsVxzOtsjxPyJpPf.png)

Context Test Setのダイアログで対象の項目を選択し、「Backtest」をクリックすると、現在のScript Versionを使ってバックテストを実行できます。クリック後、テストが自動的に開始され、結果が出力されます。

![](/images/ja/test-center/コンテキストテストセットとバックテスト/img-NbzAbvtKfo1xN4xx4czjoPmjpWe.png)

選択した項目を会話のコンテキストとして使用した場合に、AI Agentが次のターンで返す応答の一覧がテスト結果として出力されます。

![](/images/ja/test-center/コンテキストテストセットとバックテスト/img-AcvKbQxnZouBTfxjE5Fj51OxpFh.png)

テスト結果はレポート形式で表示されます。各テストが期待どおりかどうか（PassまたはNo Pass）を手動で選択し、すべて選択したら「Save Result」をクリックしてテストを保存します。

保存したテスト結果はScript Version Detailページの一覧から確認できます。

![](/images/ja/test-center/コンテキストテストセットとバックテスト/img-JTUqbvZPKoF2LyxzThWjOhmmpQ3.png)

すべてのバックテスト結果は「Backtest Records」タブで確認できます。

![](/images/ja/test-center/コンテキストテストセットとバックテスト/img-Jk6BbiIoVoCNArxdVDGjVWBspCd.png)
