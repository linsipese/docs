---
title: "ログイン IP セキュリティ設定・ログイン履歴"
---

企業ワークスペース（Workspace）のデータを保護するため、Daisybell Agent Lab では、管理コンソールにアクセスできる IP アドレスの許可リストを設定できます。アクセス元を厳格に制御することで、許可されていないネットワークからのアクセスを効果的に遮断できます。

本書では、信頼できる IP アドレスの許可リストの設定方法と、ログイン履歴の確認方法を説明します。

---

### 1. 機能概要と適用範囲

- **適用対象**：IP 制限ポリシーは、現在のワークスペース内の管理者（Admin）とすべてのサブアカウント（Sub-user）に一律適用されます。
- **設定の保持**：IP 許可リストの有効化スイッチは、初期状態ではオフです。一時的に機能をオフにしても、設定済みの IP アドレス一覧は保持され、再度オンにすると引き続き適用されます。
- **画面と権限**：現在のワークスペースの Sub-user アカウントには、信頼済み IP アドレスの許可リストを設定したり、安全なログインログを確認したりする権限はありません。

---

### 2. 信頼済み IP アドレスの許可リストを設定する (Trusted IP Whitelist)

![](/images/ja/account-settings/ip/img-MDHGbkWLrorN93xRKUDjm5mypqe.png)

アクセス制御ポリシーは「`Settings`」→「`Login IP Security Settings`」画面で管理できます。

![](/images/ja/account-settings/ip/img-Igqkbxjg3oytAExwyFnjMTC1pOc.png)

#### 2.1 現在のネットワークをワンクリックで追加 (Quick Add)

設定を簡単に行えるよう、システムは現在のネットワークのグローバル IP アドレスと所在地（国・都市）を自動検出します。初めて設定を有効にする際は、誤操作によってご自身のアカウントがブロックされないよう、まず「**Add To Whitelist**」をクリックして現在のネットワークを許可リストに追加することをおすすめします。

![](/images/ja/account-settings/ip/img-Rw8abTyRXob0Sqxtr3wj9sOippc.png)

#### 2.2 IP アドレスまたはネットワーク範囲を手動で追加する

アクセス元の IP アドレスを手動で指定できます。システムでは、単一の IP アドレスおよび CIDR 形式のネットワーク範囲（例: `198.51.100.0/24`）を追加できます。各ワークスペースに設定できるセキュリティルールは最大 20 件です。

![](/images/ja/account-settings/ip/img-Lo9RbpOiRo1YYzxfyc4jL2lDpbg.png)

入力ミスによるサービス停止を防ぐため、システムには入力値を検証する仕組みが備わっています。

- **システムによる自動ブロック (Error Blocked)**：システムループバックアドレス（例: `127.0.0.1`）、ブロードキャスト／マルチキャストアドレス（例: `255.255.255.255`）、IPv4 形式が不正な値、またはリスト内の重複データを入力すると、Error Blocked が表示され、保存できません。
- **高リスク操作に関する警告 (Risk Warning)**：

  - **プライベート IP アドレス**：LAN 内のプライベート IP アドレス（例: `192.168.0.0/16`）を入力すると、プラットフォームではローカルネットワークのアドレスを識別できない旨が表示されます。そのまま保存するとログインできなくなる可能性があるため、正しいグローバル出口 IP アドレスを確認してください。
  - **ワイルドカード IP アドレス**：`0.0.0.0/0`の場合、すべての IP アドレスからログインできるため、許可リストによる制限が完全に無効になる旨が表示されます。​

#### 2.3 許可リストの管理

追加すると、リスト上で専用ラベルを使ってネットワークを識別できます：

- **Current IP**（緑色）：現在使用中のネットワークアドレスを示します。
- **Private IP / Wildcard IP**（黄色）：アクセスリスクがあるネットワーク、または範囲が広すぎるプライベートネットワークやワイルドカードネットワークを示します。

リスト内のルールはいつでも編集または削除できます。アクセスを保護するため、「現在使用中の IP アドレス（Current IP）」または「リスト内の最後のルール」を削除しようとすると、誤操作防止の確認ダイアログが表示されます。

---

### 3. ログイン履歴 (Login Log)

「`Settings`」→「`Login Log`」画面では、アカウントを保護するために、ワークスペースへの管理者アクセス履歴を確認できます。

![](/images/ja/account-settings/ip/img-V11Ebd1Fxoj7FbxQ8FgjXhFPpLg.png)



- **記録の仕組み**：IP 許可リストが有効かどうかにかかわらず、システムは管理コンソールへのログイン履歴を記録します。\*（注：パスワードやアカウントの誤りなどによる通常のログイン失敗は記録されません。）\*。
- **ログ項目**：ログは新しい順に表示され、次の情報を確認できます：ログイン日時（YYYY-MM-DD HH-MM-SS）、IP/CIDR アドレス、操作アカウント、所在地（都市／国）、アクセスステータス。
- **異常アクセスの追跡**：IP 許可リスト違反によってブロックされたログインは赤色の Failed、正常にログインした記録は緑色の Success と表示されます。対象：現在のワークスペースの Admin および Sub-user アカウント。



---

### 4. アクセス拒否 (Access Denied)

- ログイン後に管理コンソールのページへアクセスする場合も、未ログインの状態でログインページからログインを試みる場合も、アクセス元が許可リストに登録されていなければ、フロントエンドでアクセスを強制的にブロックします。
- システムは、感嘆符アイコン付きの「**Access Denied**」警告ダイアログを表示し、「Your network is not authorized to access this account. Please switch to a trusted network or contact your administrator.」と通知します。これにより、不正なアクセス要求を即座に遮断します。
