title: "平台工具"
---

平臺工具（General Tools）彙集了平臺當前提供的若干管理與操作入口。根據界面菜單，現有入口涵蓋電話號碼、知識庫、匯出、訊息推送和子賬戶管理。

### 工具入口

| 菜單項 | 能力類別 | 文件地址 |
|-|-|-|
| 電話號碼管理（Phone Numbers） | 電話號碼管理 |  |
| 知識庫 Beta（Knowledge base） | 知識庫相關能力 |  |
| 匯出中心（Export Center） | 通話記錄匯出相關入口 |  |
| 訊息推送（Message Push） | 自動化通知推送平臺 |  |
| 子賬戶管理（Sub-user Management） | 子賬戶管理界面 |  |
