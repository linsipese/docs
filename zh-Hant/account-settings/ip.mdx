---
title: "登入IP安全設定 & 登入日誌"
---

爲保障企業工作區（Workspace）數據安全，Daisybell Agent Lab支持設定工作臺登入 IP 白名單。通過嚴格的訪問源控制，您可以有效攔截未經授權的外部網絡訪問。

本文件將指導您如何設定受信任的 IP 白名單並查看安全登入日誌。

---

### 1. 功能概述與生效範圍

- **生效對象**：IP 限制策略對當前工作區內的管理員（Admin）及所有子賬戶（Sub-users）均全局生效。
- **數據保留**：IP 白名單總開關預設處於關閉狀態。當您臨時關閉該功能時，已設定的 IP 列表數據將被保留，再次開啓後依然有效。
- **頁面及功能**：當前工作區的Sub-user 賬號無設定受信任的 IP 白名單並查看安全登入日誌的權限

---

### 2. 設定受信任的 IP 白名單 (Trusted IP Whitelist)

![](/images/zh-Hant/account-settings/ip/img-EU0VbUuNDoJDopx0lSRjGRIUpOb.png)

您可以在 `Settings` -> `Login IP Security Settings` 頁面中管理您的訪問控制策略。

![](/images/zh-Hant/account-settings/ip/img-NzOBbN0gRouA76xXw5Yjwmlfptf.png)

#### 2.1 一鍵添加當前網絡 (Quick Add)

爲了便捷設定，系統會自動檢測您當前所處網絡的公網 IP 地址及其歸屬地（國家和城市）。建議您在首次開啓設定時，優先點擊 **Add To Whitelist** 將當前網絡直接加入白名單，防止誤操作導致自身賬號被攔截。

![](/images/zh-Hant/account-settings/ip/img-CsMWbNFOTow7i0x8Bk3jAsZkpUz.png)

#### 2.2 手動添加 IP 或網段規則

您可以手動輸入指定的訪問源，系統支持添加單 IP 地址及 CIDR 網段（如 `198.51.100.0/24`）。每個工作區最多支持設定 20 條安全規則。

![](/images/zh-Hant/account-settings/ip/img-Jfhxb8ZGxoZgk3x3yUhjMyhep6P.png)

爲防止因設定錯誤導致服務不可用，系統內置了輸入校驗機制：

- **系統自動攔截 (Error Blocked)**：若您輸入了系統環回地址（如 `127.0.0.1`）、廣播/組播地址（如 `255.255.255.255`）、非法的 IPv4 格式或與列表中重複的數據，系統將直接提示 Error Blocked 並禁止保存。
- **高危操作預警 (Risk Warning)**：

  - **局域網私有 IP**：若您輸入局域網內網地址（如 `192.168.0.0/16`），系統會提醒您平臺無法識別本地局域網地址。若強行保存可能導致無法登入，請確認您已獲取正確的公網出口 IP。
  - **通配符 IP**：若輸入 `0.0.0.0/0`，系統將提示該設定代表允許任意 IP 登入，此操作將使白名單限制功能完全失效。

#### 2.3 管理白名單列表

添加成功後，列表會通過專屬標籤對您的網絡進行直觀標識：

- **Current IP**（綠色）：標識您當前正在使用的網絡地址。
- **Private IP / Wildcard IP**（黃色）：標識存在訪問風險或設定過於寬泛的內網與通配符網絡。

在列表中，您可以隨時編輯或刪除已設定的規則。爲保障您的訪問安全，當您嘗試刪除“當前所在 IP (Current IP)”或“列表中的最後一條數據”時，系統將觸發二次確認彈窗進行防呆保護。

### 3. 登入日誌 (Login Log)

在 `Settings` -> `Login Log` 頁面，您可以審計工作區的管理訪問記錄，以保護賬戶安全。

![](/images/zh-Hant/account-settings/ip/img-OWD5bMFIXoAcc3x7fGbjoYVBpih.png)



- **記錄機制**：無論 IP 白名單功能是否處於開啓狀態，系統均會正常記錄工作臺登入行爲日誌。\*(注：因密碼或賬號錯誤等導致的常規登入失敗行爲不記錄在內)\*。
- **日誌欄位**：日誌按時間倒序排列，支持查看：登入時間 (YYYY-MM-DD HH-MM-SS)、IP/CIDR 地址、操作賬號、所在地域（城市/國家）以及訪問狀態。
- **異常追蹤**：因觸發 IP 白名單異常而被攔截的登入行爲，其狀態將被明確標記爲紅色的 Failed，正常登入成功爲綠色的 Success。記錄範圍：當前工作區的 Admin 和 Sub-user 賬號



---

### 4. 訪問攔截 (Access Denied)

- 無論是已登入狀態下請求工作臺頁面，還是未登入狀態下嘗試登入頁登入，只要您的訪問源不在白名單內，系統將強制觸發前端阻斷策略。
- 系統會彈出帶有驚歎號圖標的 **Access Denied** 警告視窗，提示：“Your network is not authorized to access this account. Please switch to a trusted network or contact your administrator.”，確保非法訪問請求被即時攔截。
