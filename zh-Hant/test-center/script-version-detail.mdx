## Script 版本詳情

**Script Version Detail Page中可查看該版本的所有詳細資訊與設定資訊，所有該版本的測試記錄都會出現在測試記錄列表中**

<grid>
<column width-ratio="0.500000">
#### 版本資訊（Version Info）
- Script Version存檔名，版本號，版本狀態，版本建立人及建立時間
- 如果爲Published版本，將顯示發佈人及發佈時間
</column>

<grid>
<column width-ratio="0.500000">
#### 版本設定詳情（Config Details）
- 點擊“Config Details”出現當前AI Agent Basic configuration資訊彈窗，所有設定均爲Agent Buider中設定快照，包含以下設定項：

  - Background Sound（背景音設定）
  - Max Duration（最長通話時長限制）
  - Turn Detection（完成性判斷）
  - Language Configuration（語言設定）
  - Agent Fields（Agent欄位）
  - Temporary Variables（臨時變量）
