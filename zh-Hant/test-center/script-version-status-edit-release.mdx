#### Script版本編輯與上線
- 當前Script所有已建立的版本列表，點擊後進入Script Version Detail Page
- Action（Admin-user Only）

  - Release：可以將“Built”狀態的Script Version修改爲“Released”狀態，Release之後，當前版本建立時間前的所有同級“Built”狀態的Script版本將摺疊收起爲該Version的二級列表
  - Publish：可以將“Released”狀態的Script Version 進行Publish操作，即發佈到生產環境進行運行，如果已有“Published”的Version，新發布後將被替換
</column>
