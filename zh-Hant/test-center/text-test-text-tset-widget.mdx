## 文字測試&文字測試組件

**通過文字輸入快速驗證對話邏輯。與Agent使用文字進行正常對話，所有邏輯均與實際使用語音對話保持一致，聊天面板可幫助你逐條檢查回覆，並且可以使用測試工具小組件進行局部深入測試與調試**

#### Text Test Tool Widgets

> 文字測試過程中，通過不同的測試工具小組件可以完成文字測試中不同維度的功能測試與調試

<grid>
<column width-ratio="0.500000">
##### Import Context
- 只有在點擊按鈕開始測試前可以使用該功能
- 選擇已有的上下文測試集條目點擊“Import”插入當前測試中
- Import前可以點擊“Action”中的按鈕查看條目詳情

##### Upload Test Set
- 通過此功能，用戶可以將預先整理好的大量測試用例（Test Cases）批量導入到測試運行器（Runner）中，替代手動逐一輸入，實現高效的
- 可批量添加回復條目以及對應的Agent 預期回覆，用“|”隔開，輸入框中，每一行作爲一條數據
- 支持Excel/Csv導入
- 單輪最多支持50條數據
- 所有測試結果都生成後，可選擇其中一條作爲當前測試的實際回覆，可以繼續進行測試
- 測試記錄將保留
</column>

<column width-ratio="0.500000">
##### Debug
> 提供單個測試用例的原子化分析。實時查看 LLM輸入，快速定位具體的執行錯誤
- 當對某一輪會話中AIAgent的回覆不滿意，點擊Debug按鈕，在不改變上文的前提下可以對當前輪次的LLM INPUT進行調整，並在調整後輸出新的Agent回覆
- 系統已經把Script中設定的Tool Trigger Prompt進行單獨展示，可以直接在獨立對話框中進行調整
- 完成文字修改之後，點擊“Generate”，可以生成“批量回復”結果
- 點擊“Upload test set”可進行“測試集測試”
- Debug功能中生成的結果無法保存
</column>
