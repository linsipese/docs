## 語音測試

<grid>
<column width-ratio="0.500000">
**1. 設備設定**  
測試前，請在測試界面頂部的 **Settings** 中設定測試設備，音頻輸入輸出設備不完整將影響測試
</column>
<column width-ratio="0.500000">
![](/images/zh-Hant/test-center/voice-test/img-Qis5bMsGXoTRjTxJpghjBXZ3pmb.png)
</column>
</grid>



<grid>
<column width-ratio="0.500000">
**2.環境設定：** 在測試頁面右側的 **Settings** 中，完成語音模型、語言偏好、音頻參數設定，並關聯所需的 API 工具集。
- 開始測試前，設定當前測試所需的Agnet欄位(含“Is system”欄位和“Custom”欄位）和臨時變量的值
- 還可以設定“Customized Tools”使用的API（測試沙河或者正式API） （暫時未上線）
</column>
<column width-ratio="0.500000">
![](/images/zh-Hant/test-center/voice-test/img-GaBxbB2ito82yVxAe1mjr2FUp3b.png)
![](/images/zh-Hant/test-center/voice-test/img-E4AHbcPd4ooEDXxubsBjqthjpEg.png)
</column>
</grid>

<grid>
<column width-ratio="0.500000">
**3.實時測試：** 點擊錄音按鈕，通過麥克風輸入測試語料。系統將實時捕獲並處理音頻。
</column>
<column width-ratio="0.500000">
![](/images/zh-Hant/test-center/voice-test/img-S1FqblN10oDCNZxSnDXjiODFpxb.png)
</column>
</grid>

<grid>
<column width-ratio="0.500000">
**4.Evaluate & Save Test**
完成測試內容的預覽之後需要對當前測試進行保存與評價，保存後的測試可以通過Script Version Detail中的列表進行查看
</column>
<column width-ratio="0.500000">
![](/images/zh-Hant/test-center/voice-test/img-UsXLbANzForVkSxBHdejJ2qopeg.png)
</column>
</grid>
