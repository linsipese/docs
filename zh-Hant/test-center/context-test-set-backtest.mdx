## 上文測試集

Context Test Set是測試者在所有Script Version的測試中保存的Context條目組成的集合

測試者在所有Script版本的文字測試中通過”Save Context“功能保存的條目均可以在列表中查看

![](/images/zh-Hant/test-center/context-test-set-backtest/img-CM2vbJFNSo7qQIxhHQmjyJTPpyg.png)

點擊”預覽“可查看測試集條目具體資訊

![](/images/zh-Hant/test-center/context-test-set-backtest/img-Nl0VbnioJoH6LuxYb0KjUqUBpnh.png)

回測（Backtest）

![](/images/zh-Hant/test-center/context-test-set-backtest/img-Xez0bhO1CockRTxnysFjyq97pKc.png)

在Context Test Set彈窗中選中對應的條目，點擊“Backtest”按鈕可以進行使用當前Script Version的回測，點擊“Backtest”後，系統將自動開始測試，並輸出測試結果

![](/images/zh-Hant/test-center/context-test-set-backtest/img-OeQGbdGjdomIEpxXCY6jm84bpqd.png)

輸出的測試結果爲根據選中的條目作爲上文，AI Agent的下輪次的回覆集合

![](/images/zh-Hant/test-center/context-test-set-backtest/img-ABoObXbLyo1YMwxQduJjuGt5pzg.png)

在測試結果將以報告的形式展現，測試者還可以手動選擇每一條測試是否符合預期（Pass or No Pass），全部選擇完畢後點擊“Save Result”，這次測試將被保存

保存好的測試結果可以在Script Version Detail Page的列表中查看

![](/images/zh-Hant/test-center/context-test-set-backtest/img-W4yabAoRXo0q5ex3wD5jP3nopUb.png)

所有“回測”結果可以在“回測記錄”Tab中查看

![](/images/zh-Hant/test-center/context-test-set-backtest/img-VyiobwL7OoGNuAxgFfOjblOcpeh.png)
