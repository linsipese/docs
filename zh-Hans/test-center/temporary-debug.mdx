---
title: "临时调试（Temporary Debug）"
---

在进行对话测试时，若发现 AI 表现不符合预期，您无需发布或生成新的 `Script` 脚本版本，即可在独立的沙盒调试面板中实时调整 `Prompt`、修改 `Tools` 触发描述Prompt，并一键完成单轮验证

---

### 1. 功能概述

在进行复杂的对话交互测试中，针对 AI Agent 的微调通常需要频繁地修改 Prompt 或 Tool触发描述。传统流程需要“修改Script - 保存版本 - 重新测试”，步骤较长。

**临时 Debug** 提供了一个轻量级的即时调试空间。它允许您在对话流的任意一轮中“就地调试”，在不破坏当前上下文的前提下，临时修改底层的系统 Prompt、工具（Tools）触发描述等，并支持同时并行生成多组结果。

---

### 2. 开启临时 Debug

要对某一轮次的对话进行单轮调试，请按照以下步骤操作：



1. **定位目标对话**：进入对话详情，在当前的文本测试交互中，找到需要调整或分析的用户回复气泡。
2. **启动 Debug 面板**：将鼠标悬停于该气泡上，点击其左侧出现的 `Debug` 按钮。

![](/images/zh-Hans/test-center/temporary-debug/img-1.png)



---



### 3. 调试面板核心配置



进入 Debug 抽屉页面后，工作区将为您还原该对话轮次的完整底层运行配置。

![](/images/zh-Hans/test-center/temporary-debug/img-2.png)

**功能模块**

| 模块 | 功能描述 | 可编辑性 | 说明 |
|-|-|-|-|
| **当前轮次用户输入** | 显示本轮对话中，用户发送给 AI Agent 的原始文本。 | 只读 | 场景还原 |
| **Prompt 文本框** | 承载本轮对话输入完整的提示词（Input Prompt）。 | 是 | Main Prompt |
| **Tools 配置区域** | 动态加载并展示当前环境下关联的所有 `Tools` 配置框（数量根据实际绑定动态渲染）。 | 是 | 右上角区分 `tool type` 标签（如 `Instruction Mode` 等） |

#### Prompt Diff 差异比对

当您对 `Prompt` 或工具描述进行了文本修改后，可通过 `Diff` 功能快速审查改动内容：

![](/images/zh-Hans/test-center/temporary-debug/img-3.png)

---



### 4. 调试结果生成

调整完 `Prompt` 或 `Tools` 触发描述后，您可以在右侧实时运行并分析 Agent 的输出质量。

![](/images/zh-Hans/test-center/temporary-debug/img-4.png)

#### 4.1 批量结果生成

1. **设置生成数量**：在 `Results` 框中，输入您希望并行生成的结果条数（支持设置 `1 - 20` 条）。
2. **执行生成**：点击右下角的 Generate按钮，产出相应数量的 Reply 选项。

### 5. 支持上传文本测试集进行测试

![](/images/zh-Hans/test-center/temporary-debug/img-5.png)

###### **调试内容不保存**

- 由于是纯粹的调试沙盒，测试集运行产生的所有临时回复与触发链路**均不进行任何物理保存**
