#### Script版本编辑与上线
- 当前Script所有已创建的版本列表，点击后进入Script Version Detail Page
- Action（Admin-user Only）

  - Release：可以将“Built”状态的Script Version修改为“Released”状态，Release之后，当前版本创建时间前的所有同级“Built”状态的Script版本将折叠收起为该Version的二级列表
  - Publish：可以将“Released”状态的Script Version 进行Publish操作，即发布到生产环境进行运行，如果已有“Published”的Version，新发布后将被替换
</column>
