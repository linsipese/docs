#### Text Test Tool Widgets

> 文本测试过程中，通过不同的测试工具小组件可以完成文本测试中不同维度的功能测试与调试

<grid>
<column width-ratio="0.500000">
##### Import Context
- 只有在点击按钮开始测试前可以使用该功能
- 选择已有的上下文测试集条目点击“Import”插入当前测试中
- Import前可以点击“Action”中的按钮查看条目详情

##### Upload Test Set
- 通过此功能，用户可以将预先整理好的大量测试用例（Test Cases）批量导入到测试运行器（Runner）中，替代手动逐一输入，实现高效的
- 可批量添加回复条目以及对应的Agent 预期回复，用“|”隔开，输入框中，每一行作为一条数据
- 支持Excel/Csv导入
- 单轮最多支持50条数据
- 所有测试结果都生成后，可选择其中一条作为当前测试的实际回复，可以继续进行测试
- 测试记录将保留
</column>

<grid>
<column width-ratio="0.500000">
##### Debug
> 提供单个测试用例的原子化分析。实时查看 LLM输入，快速定位具体的执行错误
- 当对某一轮会话中AIAgent的回复不满意，点击Debug按钮，在不改变上文的前提下可以对当前轮次的LLM INPUT进行调整，并在调整后输出新的Agent回复
- 系统已经把Script中设置的Tool Trigger Prompt进行单独展示，可以直接在独立对话框中进行调整
- 完成文本修改之后，点击“Generate”，可以生成“批量回复”结果
- 点击“Upload test set”可进行“测试集测试”
- Debug功能中生成的结果无法保存
</column>
