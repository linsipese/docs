## 上文测试集

Context Test Set是测试者在所有Script Version的测试中保存的Context条目组成的集合

测试者在所有Script版本的文本测试中通过”Save Context“功能保存的条目均可以在列表中查看

![](/images/zh-Hans/test-center/context-test-set-backtest/img-RtQjbV3Croug6gxP9pXj3ztXpPh.png)

点击”预览“可查看测试集条目具体信息

![](/images/zh-Hans/test-center/context-test-set-backtest/img-WNfnbW101oPv9oxkhmHjAhNNpCd.png)

回测（Backtest）

![](/images/zh-Hans/test-center/context-test-set-backtest/img-Dz58bducJov2nBxsaYVjtLWjpnU.png)

在Context Test Set弹窗中选中对应的条目，点击“Backtest”按钮可以进行使用当前Script Version的回测，点击“Backtest”后，系统将自动开始测试，并输出测试结果

![](/images/zh-Hans/test-center/context-test-set-backtest/img-Gi9xbuqs1oIMyHxv2f3jXYaUpse.png)

输出的测试结果为根据选中的条目作为上文，AI Agent的下轮次的回复集合

![](/images/zh-Hans/test-center/context-test-set-backtest/img-Hn8ebsB3PooS23xVPM6juwQEp8g.png)

在测试结果将以报告的形式展现，测试者还可以手动选择每一条测试是否符合预期（Pass or No Pass），全部选择完毕后点击“Save Result”，这次测试将被保存

保存好的测试结果可以在Script Version Detail Page的列表中查看

![](/images/zh-Hans/test-center/context-test-set-backtest/img-N2zRbzJtDohM5uxzNW3jKcyHpNb.png)

所有“回测”结果可以在“回测记录”Tab中查看

![](/images/zh-Hans/test-center/context-test-set-backtest/img-Q6JabxHVNowu6VxzkbJje5KQppe.png)
