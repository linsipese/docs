<grid>
<column width-ratio="0.500000">
#### 版本信息（Version Info）
- Script Version存档名，版本号，版本状态，版本创建人及创建时间
- 如果为Published版本，将显示发布人及发布时间
</column>

#### 版本配置详情（Config Details）
- 点击“Config Details”出现当前AI Agent Basic configuration信息弹窗，所有配置均为Agent Buider中配置快照，包含以下配置项：

  - Background Sound（背景音设置）
  - Max Duration（最长通话时长限制）
  - Turn Detection（完成性判断）
  - Language Configuration（语言配置）
  - Agent Fields（Agent字段）
  - Temporary Variables（临时变量）
