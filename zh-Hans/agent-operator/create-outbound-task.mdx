为了助力企业高效启动外呼业务，Daisybell 全新升级外呼任务创建与数据导入。系统能够自动兼容并纠正各类常见的线索录入格式，大幅降低因格式不合规导致的导入中断率。

---

### 1. 新建外呼任务流程 (Create Task)

在 Daisybell 工作台发起全新的外呼任务时，管理员仅需完成以下三个核心板块的配置：

#### 1.1 基础信息录入 (Basic Information)

- **任务名称 (Task Name)**：系统提供必填文本框，并在打开配置弹窗时，设置任务名称
- **业务脚本选择 (Script)**：用于指派该外呼任务关联的 AI 话术脚本。若当前工作空间内仅存在一个可用脚本，系统将默认处于选中状态，并优先关联最新创建的脚本版本。
- **呼叫优先级 (Priority)**：决定任务在呼叫队列中的流转权重，系统默认预设为 **Normal（普通）** 级别。

![](/images/zh-Hans/agent-operator/create-outbound-task/img-VZWqbYHzfomKwOxHoptjUy6Cp0e.png)

#### 1.2 呼叫时间段管理 (Call Time Setting)

您可以精细化控制外呼任务在每周的哪些时间段内允许自动拨出：

- **15分钟粒度控制**：配置页面提供了一张覆盖周日至周一、跨度为 `08:00 - 20:00` 的可视化时间配置网格，最小配置间隔细化至 15 分钟，交互界面内置滚动条，默认自动定位至 `08:00` 视图。
- **快速预设时段 (Select Preset)**：支持一键应用系统预设的快捷工作时段。应用预设后，每天的呼叫时间窗口默认配置为 `08:00` 开始至 `20:00` 结束。

![](/images/zh-Hans/agent-operator/create-outbound-task/img-PcGwbXWsQoLEPRxs4rwj4ajdpIc.png)

### 2.   外呼线索数据导入与模板规范

![](/images/zh-Hans/agent-operator/create-outbound-task/img-KtHibEvfuoQLGuxbZUAjHphHpFc.png)

系统通过标准化的数据模板，实现了大批量外呼线索的导入。

#### 2.1 外部线索字段属性约束 (Fields Specification)

导入文件所支持的字段（Fields），严格对应您提前在 Agent 字段管理中勾选了“可通过外部导入”选项的自定义字段：

![](/images/zh-Hans/agent-operator/create-outbound-task/img-GdqdbF0uAoPM0nx74a3jgLI8pPd.png)

- **唯一必填项**：在所有导入的列中，**只有“电话号码 (Phone)”为强制必填列**，其余自定义字段列（如姓名、年龄、性别、备注等）均允许留空或为空值。
- **物理容量上限**：单次上传的数据表格最多支持包含 **20 个** 字段列。如果上传的文件中超出了 20 列，系统在读取时将自动忽略超出范围的列。
- **数据格式约束**：

  - **文本类型**：单单元格最大支持输入 1,000 个字符。
  - **数字类型**：最高支持保留至 3 位小数。
  - **日期时间类型**：填入的数据需符合标准格式（如 `YYYY-MM-DD HH:mm:ss`）。
  - **布尔类型**：系统会自动将 True 或 False 映射为对应的业务判断。
  - **枚举类型**：填入的文本必须完全命中工作区预设的可用枚举元素。
  - **字符规范**：为了确保解析绝对精准，文件内的所有线索数据请尽量使用半角字符录入。

#### 2.2 下载 Excel 模板

- **结构与顺序规范**：**下载的模版是严格按照Agent字段配置生成的，务必使用模版填充对应内容，不要对任何的表头字段进行修改**

#### 2.3 上传限制

系统目前支持且仅支持扩展名为 **`.xlsx`** 的标准 Excel 文件导入。文件放置到上传区域后，前端执行基础校验，未通过文件将被直接拦截并提示上传失败：

- 单个文件的大小不得超过 **50MB**。
- 单个文件内的数据总行数必须**小于 10,000 行**。若表格超出 10,000 行，系统将弹出拦截提示并阻断上传流程。

### 3. 数据规范化

为了彻底解决因客户录入习惯差异导致上传失败，后端配置了数据规范化（Normalization）处理策略。

#### 3.1 电话号码规范化

对于强制必填的电话字段，系统在读取时会自动执行规范化

- **全/半角数字自动转换**：自动将输入的中文或日文全角数字（如 `０１２３...`）统一转换为标准的公网半角数字（`0123...`）。
- **高级两段式拨号兼容**：存储格式全面兼容两段式拨号指令，允许号码中包含 DTMF 控制字符及特殊按键符号（如 `+1234<dtmf>2367*#213`）。
- **非法字符强拦截**：如果电话号码单元格中混入了英文字母（`a-z, A-Z`）或除标准通讯符号外的其他特殊符号（如 `@` 等）
- **唯一性与存在性校验**：经过规范化清洗后的电话号码，其最终结果不能为空，且不允许与当前导入文件内的其他行数据发生重复。

#### 3.2 日期时间字段多格式识别 (Datetime / Date)

存入系统时统一将其转换为标准的 `YYYY-MM-DD HH:mm:ss` 格式

### 4. 数据预览与行内编辑 (Preview & Edit)

基础校验通过后，系统提供数据在线订正功能

![](/images/zh-Hans/agent-operator/create-outbound-task/img-EU5IbbZwooN97dxoGZZjW9QfpPg.png)

- **文件数据**：包括文件总行数 (Total)、格式正确的合格行数 (Correct) 以及包含错误的行数 (Errors)。错误行号（例如：`* Row 1, 3 have errors`）。
- **数据状态视觉高亮**：

  - **错误单元格 (Errors)**：凡是包含非法字符、重复号码、或者因电话为空等导致校验失败的单元格，背景色将自动**变红**
  - **空值单元格 (Empty)**：对于未填入数据的非必填自定义字段项，单元格背景色将自动**变黄**
- **数据过滤**：**Filter for rows with empty cells（筛选带空值行）** 和 **Filter for error rows（筛选错误行）**
- **数据编辑**

  - **自适应组件编辑**：点击操作列的编辑图标，系统会根据该列对应的底层字段数据类型（文本、枚举、布尔、数字等）自适应唤起最符合输入习惯的行内编辑组件。
  - **记录增删**：支持点击 **Add** 按钮在首行上方直接插入一个全新的空白行进行手工录入补齐，或点击删除按钮彻底移除无效或受污染的数据行。
- **确认导入**：只有当整个文件中的所有缺失内容补齐、且错误行数彻底归零（Errors: 0）时，数据才可提交
