- 欢迎使用 Daisybell Agent Lab。我们致力于为您提供一体化的 Agent 管理、观察与分析工作台，帮助您全方位追踪和提升 AI Agent 的业务表现。
- 本文档将向您介绍如何查看不同类型 Agent（呼入、外呼、文本对话、网页语音）的详细信息、分析核心数据看板、通话详情记录以及如何高效管理业务日志与自定义字段。

---

### 1. Agent 基础信息 (Profile)

在 Agent 详情页的顶部，您可以直观地查看并管理该 Agent 的核心身份信息：

- **基础设置**：包含 Agent 的名称（最高 40 字符）、可自定义上传Agent头像、专属 Title 以及 Agent 的业务类型、自定义描述。
- **Agent类型**：展示当前 Agent 关联的电话号码（Inbound 呼入与 Outbound 外呼类型将通过不同图标进行区分显示）。



![](/images/zh-Hans/agent-operator/profile-record/img-GBF3bcGMfoIWU7xkLngj1E4ophb.png)



---

### 2. 核心数据看板 (Data Summary)

针对不同类型的 Agent，系统为您提供了贴合业务场景的多维度数据看板。您可以通过右上角的时间筛选器（默认展示当天数据）自由查看所需时间段的分析结果。

#### 呼入型 (Inbound) & 网页语音型 (Webvoice)

- **总通话数**：统计该周期内成功完成（Finished）的通话数量。
- **平均通话时长**：计算平均每次有效沟通的时间成本。
- **通话时长分布**：通过柱状图直观呈现所有通话在不同时间区间（如短时或长时）的分布情况。

![](/images/zh-Hans/agent-operator/profile-record/img-RFopbDzSWo6uvOxgAZjj44tnpYf.png)

#### 外呼型 (Outbound)

- **任务统计**：包含当前周期内的总任务数与已完成任务数。
- **通话概况**：展示总拨打电话通数、接通数以及未接通数（无应答）。
- **核心转化指标**：系统会自动计算“电话接通率”（接通数 / 拨打电话通数），并提供平均通话时长与时长分布柱状图。

![](/images/zh-Hans/agent-operator/profile-record/img-GVzIbxOieoVNExxjpLwjqofPpUh.png)

#### 文本对话型 (Chatbot)

- **会话数据**：展示总对话场景数（Total Sessions）及平均对话时长。
- **交互深度**：提供总对话轮次（Total turns）以及对话轮次分布的柱状图，帮您准确评估 AI 与用户的交互粘性。

![](/images/zh-Hans/agent-operator/profile-record/img-D0ATb2u4Zo9MErxDKU9jgBBOpcc.png)

### 3. Outbound类型Agent任务与记录管理 (Records & Tasks)

#### 3.1 外呼任务管理 (Task Records)

对于 Outbound Agent，您可以在任务列表精细化管理所有外呼任务进程：

- **任务状态追踪**：实时监控任务进度，支持识别以下状态：**未开始 (Not Started)**、**执行中 (Executing)**、**暂停执行 (Paused)**、**终止 (Terminated)** 以及**完成 (Completed)**。
- **动态进度条**：可视化进度条，直观查看当前已拨打数量与任务总数的占比。
- **任务控制**：支持一键暂停或重启执行中的任务。对于无法继续的任务，可使用“终止”功能（请注意，终止为主动结束动作，触发后无法再继续执行）。

![](/images/zh-Hans/agent-operator/profile-record/img-KUuebMZsEoJj8txub5tjyM8ApBf.png)

![](/images/zh-Hans/agent-operator/profile-record/img-T4p0biPfcolDi2x4qMRjixmEpn8.png)

#### 3.2 通话/对话记录明细 (Call & Chat Logs)

所有维度的交互历史均在明细列表中沉淀

- **基础字段呈现**：默认包含开始时间、电话号码（如适用）、对话时长、对话轮数（仅 Chatbot）、以及智能生成的对话概要 (Summary)。
- **精准状态追踪**：针对外呼记录，系统会精确标记当前的客观执行状态。例如：呼叫完成 (Completed)、空号 (Notfound)、无应答 (Noanswer)、无法接通 (Unavailable)，以及 忙线 Busy等，明确指代对方线路正在通话的电路状态。
- **自定义字段显示**：您可以灵活添加或隐藏已经创建的Agent字段，并拖拽调整字段的左右展示顺序。

![](/images/zh-Hans/agent-operator/profile-record/img-UAJfbJTAAoQuyIxsAXpjeCAjpch.png)

- **筛选与导出**：

  - 支持对时间、数字、文本、枚举及布尔类型进行精准筛选，并允许多个条件叠加使用。

  ![](/images/zh-Hans/agent-operator/profile-record/img-TqNJbfiV5omYyXxHsbXjCgklpec.png)

  - 列表数据支持基于当前的筛选条件和字段排序，一键导出为 Excel 文件进行离线分析。

#### 3.3. 字段设置与工作台前端编辑(Field Settings)

为了适配复杂的业务需求，系统提供了强大的动态字段配置能力：

- **系统内置字段 (Is System)**：系统自动捕获并不可移除的核心指标（如来电号码、开始时间、结束时间、时长、概要、状态等）。
- **自定义业务字段**：可以通过工作台创建特定的自定义字段（支持文本、枚举、布尔等格式），并配置是否允许前端进行修改或设置默认值。
- **前端快捷编辑**：被授权“可在工作台修改”的自定义字段，允许运营人员直接在记录列表中进行高效的数据订正与修改

![](/images/zh-Hans/agent-operator/profile-record/img-Hj1cb2XkeoYuNhxXiD7jmQCbpmd.png)

### 4 对话记录详情页 (Record Detail)

点击明细列表中的“View Detail”，即可进入单次交互的深度沉淀页面：

- **高清晰度还原**：为您呈现无缝的对话记录还原与准确的交互时长统计（秒级向上取整）。
- **语音回放与支持**：针对语音交互，提供完整的音频播放轴以供复盘试听。
- **人工转接可视**：当通话触发人工接管时，界面内会生成清晰的转接分隔线，无缝衔接展示转接后的人工坐席（Transfer Speaker）与最终用户的完整对话流。
- **工具调用及节点切换：**在实际对话过程中，Agent会根据制定业务逻辑调用对应的工具，多节点类型的Script结构会根据判断逻辑触发节点换，这些过程都将通过对话记录右侧的卡片形式可视化的展示出来

  - 目前包含的可视化卡片包含：
  
    - Node switch
    - Phone tree switch
    - Tool Calling
    
      - Call Transfer
      - Instruction mode
      - Knowledge query
      - Hang up
      - language switching
      - Customize
    - Temporary Variable Value Change
    - Todo Items Update
