概览说明

Agent Operator 是 Daisybell Agent Lab 中用于观测和管理 Agent 运行情况的功能集合，覆盖 Agent 基础信息、业务数据、外呼任务和单轮对话分析。您可在 Agent 详情页查看基础信息及呼入、网页语音、外呼和文本对话的数据看板，并管理任务进度、交互记录和自定义字段；创建外呼任务时，可设置任务信息与呼叫时段，按模板导入并校验线索数据；通过 Analysis Trace（Alpha功能） 查看单轮对话的总耗时、Token 消耗、处理状态及 ASR、LLM、工具调用、TTS 等环节，辅助定位交互延迟或异常。
