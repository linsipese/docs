---
title: "登录IP安全设置 & 登录日志"
---

为保障企业工作区（Workspace）数据安全，Daisybell Agent Lab支持配置工作台登录 IP 白名单。通过严格的访问源控制，您可以有效拦截未经授权的外部网络访问。

本文档将指导您如何配置受信任的 IP 白名单并查看安全登录日志。

---

### 1. 功能概述与生效范围

- **生效对象**：IP 限制策略对当前工作区内的管理员（Admin）及所有子账户（Sub-users）均全局生效。
- **数据保留**：IP 白名单总开关默认处于关闭状态。当您临时关闭该功能时，已配置的 IP 列表数据将被保留，再次开启后依然有效。
- **页面及功能**：当前工作区的Sub-user账号无配置受信任的 IP 白名单并查看安全登录日志的权限

---

### 2. 配置受信任的 IP 白名单 (Trusted IP Whitelist)

![](/images/zh-Hans/account-settings/ip/img-1.png)

您可以在 `Settings` -> `Login IP Security Settings` 页面中管理您的访问控制策略。

![](/images/zh-Hans/account-settings/ip/img-2.png)

#### 2.1 一键添加当前网络 (Quick Add)

为了便捷配置，系统会自动检测您当前所处网络的公网 IP 地址及其归属地（国家和城市）。建议您在首次开启配置时，优先点击 **Add To Whitelist** 将当前网络直接加入白名单，防止误操作导致自身账号被拦截。

![](/images/zh-Hans/account-settings/ip/img-3.png)

#### 2.2 手动添加 IP 或网段规则

您可以手动输入指定的访问源，系统支持添加单 IP 地址及 CIDR 网段（如 `198.51.100.0/24`）。每个工作区最多支持配置 20 条安全规则。

![](/images/zh-Hans/account-settings/ip/img-4.png)

为防止因配置错误导致服务不可用，系统内置了输入校验机制：

- **系统自动拦截 (Error Blocked)**：若您输入了系统环回地址（如 `127.0.0.1`）、广播/组播地址（如 `255.255.255.255`）、非法的 IPv4 格式或与列表中重复的数据，系统将直接提示 Error Blocked 并禁止保存。
- **高危操作预警 (Risk Warning)**：

  - **局域网私有 IP**：若您输入局域网内网地址（如 `192.168.0.0/16`），系统会提醒您平台无法识别本地局域网地址。若强行保存可能导致无法登录，请确认您已获取正确的公网出口 IP。
  - **通配符 IP**：若输入 `0.0.0.0/0`，系统将提示该配置代表允许任意 IP 登录，此操作将使白名单限制功能完全失效。

#### 2.3 管理白名单列表

添加成功后，列表会通过专属标签对您的网络进行直观标识：

- **Current IP**（绿色）：标识您当前正在使用的网络地址。
- **Private IP / Wildcard IP**（黄色）：标识存在访问风险或配置过于宽泛的内网与通配符网络。

在列表中，您可以随时编辑或删除已配置的规则。为保障您的访问安全，当您尝试删除“当前所在 IP (Current IP)”或“列表中的最后一条数据”时，系统将触发二次确认弹窗进行防呆保护。

### 3. 登录日志 (Login Log)

在 `Settings` -> `Login Log` 页面，您可以审计工作区的管理访问记录，以保护账户安全。

![](/images/zh-Hans/account-settings/ip/img-5.png)



- **记录机制**：无论 IP 白名单功能是否处于开启状态，系统均会正常记录工作台登录行为日志。\*(注：因密码或账号错误等导致的常规登录失败行为不记录在内)\*。
- **日志字段**：日志按时间倒序排列，支持查看：登录时间 (YYYY-MM-DD HH-MM-SS)、IP/CIDR 地址、操作账号、所在地域（城市/国家）以及访问状态。
- **异常追踪**：因触发 IP 白名单异常而被拦截的登录行为，其状态将被明确标记为红色的 Failed，正常登录成功为绿色的 Success。记录范围：当前工作区的 Admin 和 Sub-user 账号



---

### 4. 访问拦截 (Access Denied)

- 无论是已登录状态下请求工作台页面，还是未登录状态下尝试登录页登录，只要您的访问源不在白名单内，系统将强制触发前端阻断策略。
- 系统会弹出带有惊叹号图标的 **Access Denied** 警告视窗，提示：“Your network is not authorized to access this account. Please switch to a trusted network or contact your administrator.”，确保非法访问请求被即时拦截。
